# 西班牙负价的跨境结构：ES–FR 耦合与"区域过剩"

> 最后更新: 2026-09-29
> 成熟度: **verified**（三区价格接入 / 日尺度强度模型 / 样本外 / 机制分位 / 有界化对照均已跑通）
> 功能: PS-040 证明负价发生在**正午窗口**（72% 的负价小时落在当地 10–16h），但份额本身钉不死水平。本流程把**跨境结构**（ES–FR 价差、法国中午价格状态、泛边界净交易）接入日尺度强度模型，检验"负价是纯国内现象还是区域耦合现象"。
> 结论一句话: **西班牙负价是"法兰西-伊比利亚区域过剩"现象，不是纯国内现象。** 最能区分负价日与非负价日的**不是**国内正午份额（r=+0.284），而是**法国在同一正午窗口是否也出现负价**（负价日 FR 中午负价小时均值 **3.37 h** vs 非负价日 **0.28 h**，r=**+0.620**；控制国内份额后残差相关仍 **+0.540**）。接入后日尺度 AUC **0.808 → 0.903**（全样本）、**0.842 → 0.916**（训练≤2024→2025）、**0.761 → 0.828**（训练≤2025→**全新 2026**）。而**物理出口量几乎不含信息**（净交易 r=+0.020，分位表平坦 27–33%），ES−FR 价差的作用**非单调**（峰值在价差≈0 处，43.9%）。⇒ 决定负价的是**"整个区域都过剩"，不是"西班牙出口不出去"**。

## 1. 背景与动机

- PS-040 把驱动量升级为"正午份额"后，全样本 MAE 只从 11.0 降到 10.4 h/月、样本外 MAE 几乎不变 ⇒ 说明**缺的不是驱动量，而是结构**。
- PS-037 曾观察到"2026 起负荷通道主导、资源通道失效"；PS-035/038 的模型全部是**国内量**（光伏、负荷、温度）。若负价本质上是区域现象，这些模型存在**结构性上限**。
- 西班牙只有 FR 与 PT 两个陆地边界（另有 MA 海底电缆与 AD）。本流程检验：外部耦合是否携带国内变量之外的信息。

## 2. 数据（含一条重要取数教训）

| 来源 | 内容 | 实测 |
|---|---|---|
| **Energy-Charts `/price`** | ES / FR / PT 日前价，**支持整年区间** | 3 区 × 4 年 = **12 次请求**取全 2023–2026 |
| Energy-Charts `public_power?country=es` | ES 光伏 / 负荷 / **泛边界净交易** | 已有缓存 |
| ENTSO-E A44/A11 | 官方邻国价与单一边界流 | 🔴 **当日不可用**（见 §8-2） |

**一致性自检**：EC 的 ES 价 vs ENTSO-E 官方 A44 逐时 **r = 0.999984**、MAE **0.006 €/MWh**（32,831 小时）。

**MIBEL 单一价**：同日同小时 **|ES−PT| 中位 0.00 €/MWh**（均值 2.55），而 **|ES−FR| 中位 9.16**（均值 23.25）
⇒ 伊比利亚（ES+PT）是**单一价市场**，葡萄牙**不构成独立的外部边界**，真正的外部耦合只有 **ES–FR**。

**"泛边界净交易"的符号裁定**（不预设符号，用两项内部检验）：

| 检验 | 结果 | 指向 |
|---|---|---|
| corr(净交易, ES 价) | **+0.37 ~ +0.50**（逐年） | 正号 = 净进口 |
| 负价小时 vs 非负价小时的净交易均值 | **−3031 MW vs −1075 MW** | 正号 = 净进口 |

⇒ 判定 **正号 = 净进口**，即 `netexp = −xtrade`；由此西班牙 2023–2026 的净出口为 **11.78 / 8.11 / 9.31 / 9.13 TWh**。
⚠ 该变量对负价几乎无信息量（r=+0.020），**其符号不影响任何结论**；引用时只应当作"泛边界合计"的量级使用。

## 3. 方法

- **日面板**（data/spain/spain_xborder_daily.csv，2023-01-01 ~ 2026-09-29，1368 日）：
  日界按 **Europe/Madrid 当地日**，正午窗口 = 当地 **10–16h**。同时输出 UTC 日界的负价小时做对照。
- **特征**：`noon_ratio`（正午份额）、`load_GWh`、`spread_noon`（ES−FR 正午价差）、
  `fr_price_noon`（FR 正午价）、`fr_negh_noon`（**FR 同窗口负价小时数 ∈ [0,6]，有界**）、`netexp_noon`。
- **模型**：日尺度 **Poisson 对数链接**（目标 = 当日负价小时数）；另有 NegativeBinomial 对照。
  用拟合强度作分数算 **negday AUC**（排序能力）；报 AIC、Pearson 离散度、逐日 MAE。
- **样本外**：训练 ≤2024 → 2025；训练 ≤2025 → **2026（全新年份）**。
- **机制**：在正午份额高于中位的子样本内，按各变量分位看负价日率。

### 4.4 机制：高正午份额日内部（n=684）

| 分层变量 | 低分位 → 高分位的负价日率 | 判读 |
|---|---|---|
| **ES−FR 价差 (€/MWh)** | 17.5 / 32.1 / **43.9** / 32.8 / 21.9 %（分位 −134/…/−17/…/0/…/+9/…/+268） | **非单调**，峰值在**价差≈0**（价格耦合） |
| **净出口 (GW)** | 28.5 / 32.8 / 30.9 / 30.7 / 27.0 % | **基本平坦** ⇒ 无信息 |
| **FR 同窗口负价小时 (h)** | 0–4 h：**18.9%**（1.05 h/日）｜5–6 h：**80.5%**（5.65 h/日） | **近乎充分的判别条件** |

⇒ 三张表一致指向同一机制：负价需要**整个区域同时过剩**。西班牙"出口不出去"（价差极大）反而**降低**负价概率；
物理出口量（净出口）与负价无关；**法国同窗口也负价时，西班牙几乎必然负价**。

## 5. 结论

1. **负价是区域现象，不是纯国内现象**：最能区分负价日的是**法国同窗口的负价状态**（r=+0.620；残差 +0.540），
   而非国内正午份额（r=+0.284）。
2. **接入 FR 状态后模型能力大幅提升且样本外成立**：全样本 AUC 0.808→0.903，训练≤2024→2025 0.842→0.916，
   训练≤2025→**2026** 0.761→**0.828**（MAE 2.51→1.91）。⇒ 这为 PS-037 的"2026 起国内资源通道失效"提供了新解释：
   **缺的是跨境/区域通道，不只是负荷通道**。
3. **物理出口量不含信息，价格耦合才含信息**：净出口 r=+0.020、分位平坦；ES−FR 价差非单调、峰值在价差≈0。
   ⇒ 机制是"**区域共同过剩**"，不是"西班牙出口受阻"。
4. **PT 不重要**：MIBEL 单一价（|ES−PT| 中位 0.00 €/MWh），只有 **ES–FR** 值得建模。
5. **本流程不给出新的秋季 2026 数字**：该模型需要 **FR 价格预报**，而当前链路没有（诚实缺口）。
   但它给出了明确的条件结构：**P(西班牙负价日 | 区域正午过剩)** 而非 P(负价日 | 国内份额)。

## 6. 局限

1. **净交易为泛边界合计**（FR+PT+MA+AD），不是单一 FR 边界；单一边界需 ENTSO-E A11，当日网关不可用（§8-2）。
2. **FR 负价小时是"同期观测"而非预报量**：本流程证明它是关键条件变量，但**没有**把它变成可预报量
   （需 FR 的光伏/核电/负荷与 FR 侧模型）。
3. **过度离散未消除**（离散度 4.5–5.9）；NB 对照显示计数波动本身很大，标准误被低估。
4. 日尺度、日前价口径；未纳入日内/实时、也未纳入储能与需求响应。
5. 2023 年负价为 0，对"低尾"的约束强而对"高水平"的约束弱（与 PS-039 同一结构性问题）。

## 7. 下一步

1. **把"FR 正午负价"建成可预报量**：用 EC 的 FR 光伏/负荷/核电 + 天气，做 FR 侧正午过剩模型；
   再与本模型拼接，得到**条件概率** P(西班牙负价日 | 区域过剩)。
2. 把该条件结构接回 PS-039/040 的秋季口径，替换"国内份额阈值"的单变量外推。
3. 用 **NegativeBinomial / 准泊松** 处理过度离散并重算区间。
4. 待 ENTSO-E 网关恢复后补 **A11 单一 FR 边界**流量，把"泛边界合计"替换为"ES–FR 专向"。
5. 引入**储能与需求响应**（西班牙 2026 储能增长快），检验其是否抬高"区域过剩"的负价门槛。

### 🔴 工程陷阱（本流程新增）

1. **对数链接 + 无界水平变量 = 外推定时炸弹**：设定 S7 把 **FR 正午价水平**放进 Poisson 对数链接，
   训练≤2024→2025 时 AUC 0.909 表现最好之一，但训练≤2025→2026 时 **MAE 爆到 160.4 h/日、偏差 +156.8**
   —— 因为 2026 年 FR 正午价跌出训练区间（最低 **−498 €/MWh**），`exp()` 把线性外推指数级放大。
   **改用有界特征**（"FR 同窗口负价小时数"∈[0,6]）后同一窗口 MAE **1.91**、偏差 −0.93。
   ⇒ 凡可能越出训练区间的水平变量（价格、净额）应换成**计数/占比/分位/指示**，或加饱和变换。
2. **ENTS0-E 网关会限流到不可用**：连续按月请求 A44 FR 约 30 次后，单月请求开始 **90 s read timeout**
   或 **HTTP 599**（`uu-gateway-router/connectTimeout`）；此后连"整年区间"也失败。
   ⇒ 邻国价格改走 **Energy-Charts `/price`**（免注册、支持整年区间），12 次请求即取全部；
   与官方逐时 r=0.999984，可安全互替。
3. **PT 的 EIC 取不到**：`10YPT-REN------9/-8/-C/-0` 四个候选对 A44 全部返回 **0 行**，A11 `ES→PT` 亦为空。
   叠加 MIBEL 单一价的事实 ⇒ **葡萄牙不需要单独建模**，直接用 ES 价即可（并在文中声明）。
4. **"泛边界合计" ≠ "单一边界"**：EC 的 `Cross border electricity trading` 是**泛边界合计**；
   与 ENTSO-E A11 的"净 ES→FR"相关 r=0.80 但**水平不同号**（2026-08：合计 −1655 MW vs 净 ES→FR +589 MW）。
   两者不可混用；要单一边界必须走 A11。
5. **比率型特征会产生 `inf` 并污染 GLM**：当日正午负荷窗口和为 0 时 `solar/load = inf`，
   statsmodels 直接抛 `MissingDataError: exog contains inf or nans`。
   ⇒ 分母必须 `where(denom > 0)`，并在建模前统一 `replace([inf,-inf], nan).dropna()`。
6. **不预设符号，用物理关系裁定**：泛边界净交易的符号不是文档约定的，需用两项内部检验
   （与国内价的相关、以及"负价时应出口最大"）交叉裁定；本流程判定为**正号=净进口**。
   该变量恰好无信息量，因此符号不影响结论——但**方法上仍必须裁定**，否则解释会反向。
