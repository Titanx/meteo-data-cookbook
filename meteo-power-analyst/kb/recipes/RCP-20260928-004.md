# 风电缺口 × 电价：风功率物理链路与"风光不对称"（2025/2026 ERCOT）

> 最后更新: 2026-09-28
> 功能: 完成 PS-022 遗留的"风电缺口同法推演"。用 HRRR 80m 风速 + 标准功率曲线重建 ERCOT 风 fleet 资源潜力，与 EIA-930 实际风电对比，标定"风电缺口"对 RTM 电价的弹性，并与光伏链（PS-021~027）对照
> 结论一句话: **同一"缺口"概念在风光上符号相反**——光伏缺口 → 电价 **+4.5~+5.7 %/GW**（外生云致供给收缩），风电"资源潜力−实际"缺口 → 电价 **−2.8~−3.3 %/GW** 且**控实际风电后独立效应消失（≈0）**（内生弃风，本身是低价的结果）⇒ **不能把光伏弹性套到风电**；风电真正的"天气供给缺口"是**低风异常**，弹性 **+7.4 %/GW**（比光伏更强）

## 1. 背景与动机

PS-022 结论列明推广方向："风电缺口同法推演（风功率物理链路已有 WIND-Bench 验证基准）"。光伏链已建"物理反事实 → 缺口 → 弹性（+5 %/GW，四重稳健）"。ERCOT 风电装机（~38 GW）大于光伏（~31 GW）且夜间出力，是电价更重要的边际电源，必须做平行链。

**关键概念差异（本流程核心）**：光伏的晴空反事实是**确定上界**（太阳位置精确已知），缺口 = 云致供给收缩。风电的资源潜力同样可由风速算出，但**风速本身就定义资源** ⇒ `潜力 − 实际 ≈ 弃风 + 场损/可用率`，而非"低风缺口"。ERCOT 弃风集中在高风 + 低需求（夜间），因此**预计风电缺口与电价负相关**。

## 2. 数据与方法

| 环节 | 内容 |
|---|---|
| 风电清单 | GEM `gem_wind_2026-08.csv` → ERCOT bbox(26~34N, 107~94W)+operating+排墨西哥 ⇒ **202 机组 37.9 GW**，按 0.1° 去重聚合为 **165 点位**（`prep_ercot_wind_fleet.py`） |
| 风资源 | Open-Meteo 历史预报 API `ncep_hrrr_conus` **80m 风速** + 2m 气温，165 点位 × 14,736h（2025-01-01~2026-09-06），匿名免 key（`download_hrrr_wind_2025_2026.py`） |
| 功率曲线 | 标准归一化曲线（切入 3 / 额定 12 / 切出 25 m/s），场损 **η=0.90**，容量加权 fleet 潜力 |
| 实际 | EIA-930 `WND` 小时发电 + 需求；GridStatus RTM `HB_HOUSTON` |
| 缺口定义 | `w_short = 潜力 − 实际 − 逐小时偏移(q05)`（与 PS-022/024 同法，q05 吸收 HRRR 偏差与场损率选择），clip≥0 |
| 低风异常 | `w_drought = (该(小时,月)容量因子中位 − 当前容量因子) × 装机`，clip≥0 |
| 回归 | `ln(RTM) ~ X + 需求 + C(小时) + C(月)`，与 PS-022/024 同规格 |

## 3. 结果

### 3.1 物理风功率模型验证（无历史出力训练）

| 指标 | 2025 | 2026 | 合计 |
|---|---|---|---|
| 逐小时 r（潜力×实际） | 0.9542 | 0.9570 | **0.9556** |
| 能量比（潜力/实际） | 1.022 | 1.021 | 1.022 |
| 容量因子 潜力 / 实际 | 0.354 / 0.346 | 0.389 / 0.381 | — |

⇒ 纯物理链路（HRRR 80m + 标准曲线）即可复现 ERCOT 风电，误差 2.2%，与光伏 PS-021 同性质。时滞诊断：lag 0 r=0.956、lag+1 r=0.966（风自相关强，±1h 差异小）。

### 3.2 风电缺口的价格弹性：负号（与光伏相反）

| 变量（模型） | 2025 %/GW | 2026 %/GW | 解读 |
|---|---|---|---|
| **风电缺口 w_short**（wind_short） | **−2.792 (SE .326)** | **−3.315 (SE .398)** | 负，显著 |
| **低风异常 w_drought**（drought） | **+7.412 (SE .170)** | **+7.413 (SE .243)** | 正，极稳 |
| 实际风电水平 act（level） | −4.945 | −4.140 | 风多→价低 |
| 资源潜力 pot（level_pot） | −4.197 (SE .088) | −3.396 (SE .110) | 资源多→价低 |
| 白天同框（joint_day） | 光伏缺口 +4.454 / 风电缺口 −6.121 | 光伏 +5.716 / 风电 −7.121 | **同框反号** |

**机制检验 A（关键）**：加入实际风电后，缺口系数 **+0.102 (SE .293) / +0.426 (SE .386) —— 完全不显著**。共线性诊断：`corr(act, w_short)=+0.27/+0.31`（低，非共线性伪象），`corr(pot, act)=+0.95`。
⇒ **负号来自"风电水平"通道，缺口本身无独立价格效应**。

**机制检验 B（弃风指纹）**：高缺口（>P90=6.1/6.3 GW）小时出现 **<$5 负价占比 13.2% / 12.7%**，低缺口小时仅 **1.7% / 2.1%**（6~7 倍）；高缺口小时需求中位 50.0/53.2 GW（低谷）。
⇒ **缺口小时是供给过剩的标志，不是缺电**。

**机制检验 C（对齐敏感性）**：滞后 +1h 重算缺口弹性 −0.361 (SE .257) / −1.084 (SE .309) —— 负号不变、幅度收窄。

**缺口时段/工况结构**：缺口在 03UTC 3,729 MW、06UTC 3,421、21UTC 3,554 最大（夜间+晚间），负荷低谷；高风小时（>P90）缺口均值 5,056 MW vs 低风小时 2,773 MW，且高风时需求更低（53.4 vs 58.8 GW）—— 典型弃风工况。

### 3.3 光伏对称检验（说明"缺口"变量与"水平"近乎共线）

`ln(RTM) ~ pv_short + solar + 需求 + FE`：光伏缺口系数由 +3.74/+5.07 转为 **−3.04 (SE .68) / −2.54 (SE 1.00)**，光伏水平项 −7.06/−7.86 %/GW。
⇒ 因 `pv_short = 包络 − solar` 与 solar 近乎共线，二者**不可分开识别**；稳健的净效应是"光伏出力↑ → 电价↓"。**故不要过度解读单变量系数分解**；本流程的可靠结论是：(i) 光伏缺口（外生）正号、(ii) 风电缺口（内生弃风）负号且控水平后归零、(iii) 低风异常强正号。

## 4. 结论

| 结论 | 值 | 稳健性 |
|---|---|---|
| 物理风模型 | r=0.956, 能量比 1.02 | 稳健 |
| 光伏缺口 → 电价 | **+4.5~+5.7 %/GW** | 稳健（复现 PS-024 量级） |
| 风电缺口 → 电价 | **−2.8~−3.3 %/GW**（控水平后 ≈0） | 稳健（跨年、跨对齐） |
| 低风异常 → 电价 | **+7.4 %/GW** | 稳健（SE 仅 0.17~0.24） |
| 缺口的性质 | 光伏=外生云缺；风电=内生弃风 | 机制检验 A/B 支持 |

**核心结论**：**"缺口 → 电价"机制在风光上不对称，不可简单套用**。风电的"潜力−实际"缺口是**供给过剩/弃风的标记**（高缺口小时负价频率 6~7 倍），而非价格上行成因；其负弹性是"价格已低"的结果，不是"缺口压低价格"的因果。风电真正的"天气供给缺口"类比物是**低风异常**，弹性 +7.4 %/GW，单位 GW 推力强于光伏缺口。

## 5. 局限

1. **弃风量级被模型误差抬高**：校准后缺口占潜力能量 23.2%，但 HRRR 栅格风被平滑、单一功率曲线、缺空气密度/尾流方向修正 ⇒ 该 23% 应读作"潜力缺口"上界，ERCOT 官方弃风通常仅数个百分点；**变化量**才承载价格信号
2. **GEM 清单截止 2025 投产**，2026 新增风电缺失（与光伏链同一已知问题，靠逐小时偏移部分吸收）
3. **因果不可分离**：弃风的"因"与"果"无法用本数据完全区分，负弹性是标记而非因果
4. **单高度 80m**，未做空气密度（海拔）修正
5. **RTM 为 HB_HOUSTON 枢纽价**，非节点价；WIND-Bench 调研提示 HRRR 近地面风速可能偏高，宜后续做偏差订正基线（调研记录在本地 `raw/surveys/wind-bench_arxiv2026.md`，对应外部素材目录已不纳入版本控制）

## 6. 推广方向

- 用 **WIND-Bench** 观测基准订正 HRRR 80m 风速偏差，改进潜力绝对量级
- 风电**低风异常**接 PS-027 季节预报 → 未来 45 天低风风险概率化（与光伏缺口风险并列）
- 风电与储能联合：弃风时段恰好是储能充电窗口（ERCOT 弃风 + 储能充电的时间重合度）
- 节点级 RTM（2026-10 额度重置后）做风电场级冲击验证
