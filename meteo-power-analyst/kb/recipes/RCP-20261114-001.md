# Google DeepMind PARDIG + SatWeave 匿名拉取管线（GCS Zarr v3 + 并发分片）

> 成熟度: **verified**（2026-11-14 实测：两帧样例 86s 拉完 + 物理自洽通过，中国子域 lat 20–45N / lon 95–125E）
> 适用场景: 从 GCS 匿名公开桶读 Zarr v3 数据集（PARDIG 降水 / SatWeave 多光谱镶嵌，可推广到同类 GCS 公开气象数据）

## 结论先行

1. **免账号免注册**：`storage.googleapis.com` JSON API + 数据面全部匿名可达（官方文档写 "with any Google Cloud account" 过严，实测匿名即可）；文档域用 `developers.google.cn` 镜像（`.com` 超时）。
2. **国内直连单流只有 ~0.03 MB/s，但 8 连接并发 Range 分片提速 5–8 倍（近似线性）**——单帧验证从 15 分钟级降到 1 分钟级；PARDIG 降水帧 zstd 压缩比 19.7x，**26MB→1.3MB 秒级可拉**。
3. 管线五步：**startOffset 列桶定位最新帧 → obstore 匿名打开 → chunk key 构造 → 并发分片下载 → zstd 解压 + 子域切片**。
4. 数据价值口径（arXiv 2611.13941）：CSI 全面胜 IMERG-Final/MSWEP/ERA5，**25mm/h 极端 0.12 vs 现役 <0.03**（代差级），36,678 站 89.9% 胜 IMERG-Final。

## 数据集与入口路径

```
gs://pardig_1/                                                    # PARDIG 降水 (m/h, ×1000=mm/h)
├── LR/zarr/1999_to_2023/predictions.zarr                         # 空间访问 chunk (4,1801,3600)
├── LR/zarr_rechunked_as_timeseries/1999_to_2023/...              # 时间序列 chunk (time:-1,5,5)
└── NRT/zarr/2026_to_present/<YYYYMMDDTHHMMSS>/predictions.zarr   # 单帧 2D (1801,3600) precipitation
gs://satweave_1/zarr/2026_to_present/<ts>/mosaic.zarr             # 单帧 group：17 个独立波段变量
```

- PARDIG 变量 `precipitation`，单位 **m/h**（×1000 才是 mm/h）；SatWeave 每波段独立变量 `mosaic_XXX_nm`（**不是 (17,lat,lon) 立方体**），TOA reflectance units %，valid_range [0,100]。
- 帧流规模（列桶实测）：SatWeave 2026 逐时 **7622 帧**（~1h 延迟）；PARDIG-NRT 15min **30475 帧**（6h 批量入库，有效延迟 ~3.5h，官方声称 2–8h）。
- 网格：lat 90→-90（1801）、lon **0–360 约定**（3600）；中国 lon 95–125E 直接用 950:1250。
- SatWeave GEO 覆盖 ±60–65°，部分波段非全星座（470nm 仅 GOES×2+Himawari，attrs 里写明）；夜间可见光波段近 0 是正常物理。

## 管线流程

### ① startOffset 列桶定位最新帧（1–3s，勿盲目翻页）

```python
url = (f"https://storage.googleapis.com/storage/v1/b/{bucket}/o"
       f"?prefix={prefix}&delimiter=/&startOffset={prefix}{YYYYMMDD}T&maxResults=1000")
data = json.loads(urllib.request.urlopen(urllib.request.Request(url), timeout=60).read())
dirs = data.get("prefixes", [])   # 子目录在 prefixes 字段（delimiter=/ 时 items 为空）
```

**坑**：`maxResults=1000` 截断——盲列 30475 帧只回 999 个前缀，"最新帧"会错停在旧日期（实测 SatWeave 停在 20260211）。要么 `pageToken` 翻到底（67s），要么 `startOffset` 前缀过滤（推荐）。

### ② obstore 匿名打开（两个必传参数）

```python
from obstore.store import GCSStore
from zarr.storage import ObjectStore
import zarr

raw = GCSStore(bucket="satweave_1", prefix="zarr/2026_to_present/<ts>/mosaic.zarr",
               skip_signature=True,                      # 必须！默认会去请求 GCE metadata 取 token
               client_options={"timeout": "600s"})       # 默认超时拉 26MB chunk 会 Body TimedOut
g = zarr.open(ObjectStore(raw), mode="r")
```

**坑 ①**：本机/非 GCP 环境 `GCSStore(bucket, prefix)` 直接报 `NetworkUnreachable`（169.254.169.254）——必须 `skip_signature=True`。
**坑 ②**：zarr 3.4.2 支持 v3；环境：`pip install zarr obstore zstandard`。

### ③ chunk key 构造（zarr v3 default encoding）

```python
key = "c/" + "/".join(["0"] * arr.ndim)   # 3 维数组 → c/0/0/0（不是 c/0，猜错 404）
```

元数据先看 zarr.json：codecs = `bytes(little) + zstd(level 0)` → **有压缩，HTTP Range 部分读无效**，读子域也要整 chunk 下载。

### ④ 并发分片下载（提速核心）

```python
def parallel_pull(bucket, obj, n_conn=8):
    size = int(urllib.request.urlopen(urllib.request.Request(
        media_url(bucket, obj), method="HEAD"), timeout=60).headers["Content-Length"])
    step = (size + n_conn - 1) // n_conn
    ranges = [(i * step, min((i + 1) * step - 1, size - 1)) for i in range(n_conn)]
    with ThreadPoolExecutor(n_conn) as ex:
        parts = list(ex.map(lambda i: fetch_range(bucket, obj, *ranges[i]), range(n_conn)))
    return b"".join(parts)     # 每段独立 Range，GCS 206 生效
```

实测：SatWeave 波段 chunk 16.8MB@75s=0.22MB/s（单流 0.03 → **7x**）；PARDIG 帧 1.3MB@8.6s。

### ⑤ 解压 + 子域切片

```python
arr = np.frombuffer(zstandard.decompress(buf), dtype="<f4").reshape(shape)
sub = arr[LAT0:LAT1, LON0:LON1] * 1000.0    # PARDIG m/h → mm/h
```

压缩比差异大：SatWeave TOA 反射率 **1.5x**（浮点连续场）；PARDIG 降水 **19.7x**（大片 0 值）。17 波段全帧 ≈280MB 未压缩 → 批量拉全波段仍需海外出口。
