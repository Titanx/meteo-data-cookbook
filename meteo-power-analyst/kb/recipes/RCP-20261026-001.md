# ERA5 长期风序列与 IGCC 气候指标双匿名通道（风电长期投资视角）

> 最后更新: 2026-10-26
> 成熟度: **verified**（2026-10-26 实跑：两风电区 1940–2025 86 年年表拉齐、IGCC-2025a 全包 125 文件下载解包、趋势/波动统计输出）
> 适用场景: **风电长期投资收益分析**——P50/P90 论证需要"风资源长期稳定性"年代表；气候风险披露（TCFD/物理风险）需要官方锚点指标。
> 通道定位: 全部**免注册匿名**（CDS 正式通道需账号，见第 4 节绕行）；Open-Meteo 与怀俄明/IGRA 探空互补（网格再分析 vs 站点廓线）。

## 0. 结论速览

- **ERA5 经 Open-Meteo Archive**：`archive-api.open-meteo.com/v1/archive`，1940 起逐时，匿名免费（非商业 ~10k 请求/日），后端 ERA5 0.25° 网格。
- **IGCC 气候指标经 Zenodo**：CDS retrieve 匿名 401，但 IGCC 团队官方存档在 Zenodo（doi:10.5281/zenodo.21494229，与 CDS 同版本 `igcc_2025a`，CC-BY-4.0，1.50 MB 全包）。
- 两个量级/口径坑必须防 ⇒ 见 `pitfalls/PIT-20261026-001`（km/h 默认单位 / pre-1979 同质性 / IncompleteRead）。

## 1. 通道一：ERA5 长期序列（Open-Meteo Archive）

| 参数 | 值 | 说明 |
|------|-----|------|
| 端点 | `https://archive-api.open-meteo.com/v1/archive` | 与 forecast-api（预报）是**不同域**，别混 |
| 必传 | `latitude, longitude, start_date, end_date, hourly` | `hourly=wind_speed_100m,wind_direction_100m,temperature_2m` |
| **单位** | `wind_speed_unit=ms` | ⚠️ 默认 **km/h**，不传则 100m 年均显示"29 m/s"（实为 8.1） |
| 时区 | `timezone=UTC` | 默认 GMT，年聚合前显式声明 |

**分段策略**：86 年逐时 ≈ 75 万行，单请求按 **10 年段**（~8.8 万行 JSON ≈ 10 MB）拉 9 次/点；段间 `sleep 1.5s` 礼貌限流。年聚合时**完整年判定**（有效小时 >8000 才收），防不完整年污染均值。

**ERCOT 风电区代表点（实测）**：Panhandle `35.19N, 101.45W`；West Texas `31.95N, 102.15W`。

## 2. 实测结论（86 年年表，投资视角）

- 两点趋势 **+0.01 m/s/decade 级**，可忽略；pre-1979 与 post-1979 均值几乎相同（7.75/7.78、7.11/7.15）。
- 年际波动 ±8–10%（最低 1941、最高 1951，均在早期）。
- **投资含义**：P50 不稳定来自年际波动而非气候趋势——收益不确定性按年际离散度建模，不按趋势外推；1940–1978 段慎入主样本（卫星同化 1979 起才完整）。

## 3. 通道二：IGCC 全球气候指标（11 项，1750–2025）

| 项 | 内容 |
|----|------|
| 是什么 | IPCC AR6 指标年度滚动更新：GHG 排放/浓度 → 辐射强迫 → 能量失衡 → 全球温度 → 归因 → 碳预算 → 海平面/海洋热浪/陆地极端/降水 |
| CDS 正式通道 | `cds.climate.copernicus.eu/api/retrieve/v1/processes/multi-origin-igcc-climate-change-indicators`——**需注册 + API key**（匿名实测 401）；元数据（STAC catalogue）匿名可查 |
| **Zenodo 匿名通道** | 搜 `"Indicators of Global Climate Change"` 精确短语 → doi:10.5281/zenodo.21494229（IGCC-2025a，与 CDS 同版本），单 zip 125 文件（data/CDS 下 csv 与 nc 双子目录），文件名模板 {indicator}_{domain}_{type}_{...}_IGCC-2025a.csv |
| 关键序列 | `temperature-observed`：1850–2025 年表，**2025 年 GMST +1.391°C**（vs 1850–1900）；`co2-budget`：参数×目标×置信度矩阵表 |

**注意边界**：11 项指标**无风速/风资源项**——风资源长期趋势必须走通道一（ERA5）；IGCC 用于气候叙事与压力测试背景层，不进逐时电力管线。

## 4. 脚本骨架

```python
import json, time, urllib.request

H = {"User-Agent": "Mozilla/5.0"}

def get(url, timeout=300):
    return urllib.request.urlopen(urllib.request.Request(url, headers=H), timeout=timeout).read()

def annual_wind(la, lo, y0, y1):
    """10 年段拉取 -> 按年聚合 100m 均值 (m/s)"""
    out = {}
    for a in range(y0, y1 + 1, 10):
        b = min(a + 9, y1)
        u = (f"https://archive-api.open-meteo.com/v1/archive?latitude={la}&longitude={lo}"
             f"&start_date={a}-01-01&end_date={b}-12-31&hourly=wind_speed_100m"
             f"&wind_speed_unit=ms&timezone=UTC")
        d = json.loads(get(u))["hourly"]
        for t, v in zip(d["time"], d["wind_speed_100m"]):
            if v is not None:
                out.setdefault(int(t[:4]), []).append(v)
        time.sleep(1.5)
    return {y: sum(v) / len(v) for y, v in out.items() if len(v) > 8000}

# IGCC: Zenodo 记录 API 拿 files -> 带 Referer 下载 (需重试防 IncompleteRead)

```

## 5. 下载后核验（必做）

- [ ] **单位量级 sanity check**：100m 年均应落 5–10 m/s 量级（再分析网格）；>20 m/s 说明忘了 `wind_speed_unit=ms`
- [ ] 完整年判定：年有效小时 >8000 才进年表（2025 是完整年，含 8784 闰年行）
- [ ] pre/post-1979 对比：均值差应 <0.5 m/s（本例 0.03–0.04），若早期段异常偏低 → 该点同化资料稀疏，缩样本起点
- [ ] Zenodo 文件字节数 == API 声明 size（IncompleteRead 截断可差几 KB）
- [ ] IGCC csv 列语义按文件头（每文件自带说明行），勿跨指标套模板
