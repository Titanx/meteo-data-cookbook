## 0. 结论速览

- **免费、无 key、匿名直下**：NOAA/NCEI 归档全球 2932 站探空（811 站近实时），
  每站一个 zip（内为定宽 ASCII），月平均/派生/站史另设目录。

## 2. 格式要点（官方列号，1-based）

**头记录**（`#` 开头）：ID(2–12) YEAR(14–17) MONTH(19–20) DAY(22–23) HOUR(25–26，名义时次) RELTIME(28–31，施放 HHMM) NUMLEV(33–36，层数) P_SRC(38–45) NP_SRC(47–54) LAT(56–62，度×1e4) LON(64–71)。

**数据记录**：LVLTYP1(1–1，1=标准等压面/2=其他气压层/3=非气压层) LVLTYP2(2–2，1=地面/2=对流层顶) ETIME(4–8，MMMSS) **PRESS(10–15，Pa)** PFLAG(16) **GPH(17–21，m 海拔)** ZFLAG(22) **TEMP(23–27，0.1 °C)** TFLAG(28) RH(29–33) DPDP(35–39) WDIR(41–45) **WSPD(47–51，0.1 m/s)**。

单位速查（易差一个量级）：气压除以 100 得 hPa；温度/风速/RH/露点差**除以 10**；高度已是米；
LAT/LON 除以 1e4。缺测：**-9999** 原缺，**-8888** QA 剔除——都不能进平均/作图。
PFLAG/ZFLAG/TFLAG 合法值含**空白**（未做气候学检查），不能用空格 split 解析。

## 4. 下载+解析脚本骨架

```python
import io, zipfile, urllib.request

ROOT = "https://www.ncei.noaa.gov/data/integrated-global-radiosonde-archive"
HDR = {"HEADREC":(1,1),"ID":(2,12),"YEAR":(14,17),"MONTH":(19,20),"DAY":(22,23),
       "HOUR":(25,26),"RELTIME":(28,31),"NUMLEV":(33,36),"P_SRC":(38,45),
       "NP_SRC":(47,54),"LAT":(56,62),"LON":(64,71)}
DAT = {"LVLTYP1":(1,1),"LVLTYP2":(2,2),"ETIME":(4,8),"PRESS":(10,15),"PFLAG":(16,16),
       "GPH":(17,21),"ZFLAG":(22,22),"TEMP":(23,27),"TFLAG":(28,28),"RH":(29,33),
       "DPDP":(35,39),"WDIR":(41,45),"WSPD":(47,51)}

def fetch(sid, subdir="data-y2d"):
    url = f"{ROOT}/access/{subdir}/{sid}-data.txt.zip"       # y2d 需改文件名后缀见上表
    blob = urllib.request.urlopen(urllib.request.Request(url), timeout=300).read()
    return zipfile.ZipFile(io.BytesIO(blob)).read(
        zipfile.ZipFile(io.BytesIO(blob)).namelist()[0]).decode("utf-8", "replace")

def parse(text):
    snds, hdr, lv = [], None, []
    for line in text.split("\n"):
        if not line.strip(): continue
        if line.startswith("#"):
            if hdr: snds.append((hdr, lv))
            hdr = {k: line[a-1:b].strip() for k,(a,b) in HDR.items()}
            lv = []
        else:
            lv.append({k: line[a-1:b].strip() for k,(a,b) in DAT.items()})
    if hdr: snds.append((hdr, lv))
    return snds

def num(d, k):   # 缺测/QA 剔除 → None, 其余按列单位缩放
    v = d[k]
    return None if v in ("-9999","-8888") else int(v)/10 if k in ("TEMP","WSPD","RH","DPDP") else int(v)
```

- y2d 与 por 的文件名模板不同（`-data-beg{YYYY}.txt.zip` vs `-data.txt.zip`）
- 定宽切片 `line[a-1:b]` 保留空白 flag 列，**不要**用 `split()`

## 5. 下载后核验（必做）

- [ ] **NUMLEV 一致性**：每条记录 `int(hdr["NUMLEV"]) == len(levels)`（实测 582 条 0 mismatch）
- [ ] 地面层量级：PRESS ≈ 站高对应气压（南京 32 m → 1023 hPa、CRP 15 m → 1017 hPa）；
      GPH ≈ 站海拔；美国站 00/12Z 应双时次齐全
- [ ] 数据源编码：美国站 P_SRC 应为 `ncdc-nws`，中国站 `ncdc-gts`；异常源说明该站走了数字化历史档案
- [ ] 缺测率：主变量（PRESS/TEMP/WSPD）应 <5%；**RH 列中国站大面积 -9999 属正常**
      （南京 2026 文件整体 14.29%，其中 RH 贡献占绝对多数）
- [ ] 延迟预期：y2d 最新记录应落后当前时间 ≤2 天（文档口径；实测南京落后约 2 天、CRP 约 1 天）
