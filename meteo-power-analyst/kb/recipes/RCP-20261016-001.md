# 德州 ASOS 机场逐时观测批量下载流程（IEM 通道）

> 最后更新: 2026-10-16
> 成熟度: **verified**（2026-10-15/16 实跑：33 站 × 2020–2025 六年，全部成功，每站约 5.2 万行，核心字段缺失率 <0.5%）
> 适用场景: ERCOT 主线需要**站点观测真值层**（验证 NWP 插值、风/降水直接取数）时走本流程。
> 数据定位：比 Meteostat 聚合更"真"的原始观测（含 METAR 原文列可校验量纲），且不受其"预报混进观测"坑影响（`PIT-20260930-007`）。

## 0. 结论速览

- **免费、无 key、匿名直下**：IEM（爱荷华州立大学 mesonet）归档了全美 ASOS 逐时报文，
  一个 HTTP GET 返回整段 CSV（含 METAR 原文列），单站六年量级约 5 万行。
- 通道参数有两个**已实测的坑**：`missing=blank` 已废弃（会 422）、站清单端点已改版
  （返回 HTML）⇒ 见 `pitfalls/PIT-20261016-001`。
- **近实时补充通道**：aviationweather.gov 的 METAR API（原始报文），适合拿最新几小时。

## 1. 端点与参数（实测有效）

```
https://mesonet.agron.iastate.edu/cgi-bin/request/asos.py
  ?station=KDFW
  &data=tmpf&data=dwpf&data=relh&data=drct&data=sknt&data=gust&data=p01i&data=alti&data=mslp&data=vsby
  &year1=2020&month1=1&day1=1
  &year2=2026&month2=1&day2=1
  &tz=Etc/UTC&format=onlycomma&missing=M&trace=T&latlon=no&elev=no
  &report_type=3
```

| 参数 | 取值 | 说明 |
|------|------|------|
| `station` | `KDFW` 等 ICAO 四字码 | 一次一个站；多个站分别请求 |
| `data` | `tmpf dwpf relh drct sknt gust p01i alti mslp vsby` 等 | 想要的列，逐个 `&data=` 叠加；还有 `metar`（原文列）可加 |
| `year1/month1/day1` ~ `year2/...` | 日期区间 | **左闭右开**：要含 2025-12-31 就把 `year2=2026, month2=1, day2=1` |
| `tz` | `Etc/UTC` | 时间戳列 `valid` 直接是 UTC，下游对齐省事 |
| `format` | `onlycomma` | 只要数据 CSV；默认页面会带说明头 |
| `missing` | **`M`** | ⚠️ `blank` 已废弃（422），见 `pitfalls/PIT-20261016-001` 坑 1 |
| `trace` | `T` | 微量降水记 `T` 字符 |
| `report_type` | `3` | 只取**例行逐时报文**；不传会混入 SPECMI 特殊报、补发报，行数翻倍且时次不齐 |
| `latlon` / `elev` | `no` | 不需要时可省两列 |

**返回**：CSV，首行表头（`station,valid,tmpf,...,metar`），UTF-8，直接可用 pandas 解析。

**单位是英制**（IEM 不换算）：`tmpf/dwpf` °F、`sknt/gust` 节、`p01i` 英寸、`alti/mslp` inHg。
下游换算：°C=(°F−32)×5/9；m/s=kt×0.5144；mm=in×25.4；hPa=inHg×33.8639。

## 2. 近实时补充：aviationweather METAR

```
https://aviationweather.gov/api/data/metar?ids=KDFW&format=raw
```

返回**原始报文**（无解析列）。适合：① 最新几小时的观测（IEM 归档有约 1 天滞后）；
② 与 IEM 解析列交叉验证量纲（`12008KT` ⇒ `sknt=8` 节，正是 `PIT-20260930-007` 里对
Meteostat 复核用的同一对照法）。

## 4. 批量下载脚本骨架

```python
import requests, gzip, csv, io, time

STATIONS = ["KAMA","KDHT", ...]   # 上表 33 站
BASE = ("https://mesonet.agron.iastate.edu/cgi-bin/request/asos.py"
        "?station={sid}"
        "&data=tmpf&data=dwpf&data=relh&data=drct&data=sknt&data=gust"
        "&data=p01i&data=alti&data=mslp&data=vsby&data=metar"
        "&year1=2020&month1=1&day1=1&year2=2026&month2=1&day2=1"
        "&tz=Etc/UTC&format=onlycomma&missing=M&trace=T"
        "&latlon=no&elev=no&report_type=3")

for sid in STATIONS:
    r = requests.get(BASE.format(sid=sid), timeout=300)
    if r.status_code != 200 or len(r.text) < 1000:
        log_status(sid, "FAIL", r.status_code); continue
    n = len(r.text.splitlines()) - 1
    with gzip.open(f"data/asos/{sid}.csv.gz", "wt", encoding="utf-8", newline="") as f:
        f.write(r.text)
    log_status(sid, "OK", rows=n)
    time.sleep(1.5)          # 限速礼貌
```

- **逐站全期一次请求**（六年一整段）即可，无需分年；单站约 10–60 s
- 产出落 `data/asos/*.csv.gz`（每站一个 gzip CSV）
- 重跑幂等：已存在且行数一致的站跳过

## 5. 下载后核验（必做）

- [ ] 行数量级：每站每年约 8,760 行，六年 **≈5.2 万行**；明显偏少 ⇒ 查 `report_type`/站号
- [ ] `valid` 时间轴：UTC、逐时连续；`tmpf` 缺失率（`M` 占比）应 <1%
- [ ] 物理量级抽检：`tmpf` 均值应在 40–80 °F（德州六年均值实测 69.5 °F）；
  `sknt` 均值 5–12 kt
- [ ] `p01i` **量纲陷阱**：缺测填 `M`、微量填 `T`，且**逐时增量的口径要抽站核对**
  （求和前先做物理上限过滤，如 >2 in/h 的行单独列出人工确认，历史上踩过"均值 160 in/h"的荒谬结果）

## 6. 产出与下游

- 数据：`data/asos/*.csv.gz`（IEM 原始英制 30 列 + METAR 原文）
- 本次实跑：33/33 成功，约 170 万行，`tmpf/sknt/relh` 缺失率 <0.5%
- 下游对齐：`valid` 是 UTC；ERCOT 电价/负荷也是 UTC（`RCP-20261003-002`），
  可直接 merge；若要当地小时（昼夜循环分析）再 `tz_convert('America/Chicago')`
