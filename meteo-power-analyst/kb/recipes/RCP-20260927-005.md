# 光伏缺口 × 电价冲击推演流程（晴空反事实 + RTM 弹性标定）

> **类型**: process
> **成熟度**: verified
> **创建时间**: 2026-09-27
> **最后引用**: 2026-09-27
> **标签**: pv, solar, clearsky, counterfactual, shortfall, elasticity, rtm, price, panel-regression, hrrr, temperature, uscrn, ilr, eia-930, ercot, solis, event-attribution
> **适用阶段**: implement, verify, analyze

## 背景

PS-021 打通了 NSRDB 辐照 → pvlib 出力 → EIA-930 验证的物理链路 (r=0.9976)，
但热浪期正午仍低估 10~20%。本流程在其上完成三件事：
**① 温度链路修复**（HRRR 实测温度 + ILR 重标定）、**② 骤降事件归因**（云主导判定）、
**③ 缺口→电价弹性标定与冲击推演**（2025/2026 RTM 面板 → 2022-07 事件外推）。

## 内容

### 1. 温度链路修复（HRRR 2m 实测温度替换参数化）

- NSRDB 辐照/ancillary 文件均**无表面温度**（ancillary 只有气压/AOD/PWAT 等大气参数）
  → 用 Open-Meteo historical-forecast-api 的 `ncep_hrrr_conus` 2m 分析温度
- 56 站 × 744h（16.2~44.3°C），逐时线性插值到 5min
- ILR 由 1.25 上调至 **1.30**（热浪/非热浪 × 正午/全月四窗口扫描最优）
- 修复效果（热浪 07-13~18 正午窗 16-22 UTC）：偏差 **-327 → +16 MW**，MAE 405 → 273；
  全月 MAE 185 → 174 MW，能量偏差 -2.1% → +1.4%，r 保持 0.9976
- 07-18 极端日（44°C 峰值）仍残余 -4.55 GWh/日，指向温度外其他损耗（soiling/降额）
- 脚本：`download_hrrr_temp_july2022.py`、`verify_temp_fix.py`、`ilr_sweep_heatwave.py`

### 2. USCRN 地面基准交叉验证（排除卫星反演劣化）

- 数据源：NOAA USCRN subhourly01，`CRNS0101-05-2022-TX_<站名>.txt`
- **文件名每一段都有含义**（官方 readme 原文：`CRNS01TT-MM-YYYY-${name}.txt`）：
  `CRNS01` = 产品前缀（CRN Subhourly01）；**`TT` = 文件格式号（当前 `01`）**；
  **`MM` = 观测间隔分钟数（当前 `05`）**；`YYYY` = 年份；`${name}` = 站名（如 `TX_Austin_33_NW`）。
  ⇒ `05` 是"5 分钟间隔"，**不是产品版本号**；也不能按月去猜（`CRNS0101-07-2022-...` 实测 404）
- 格式：**无表头**、空格分隔 23 列；时间戳为 **5min 区间结束**（与 NSRDB 标签一致需 -5min）
- **列号必须写清基准**（2026-09-30 实测对照官方 readme）：官方字段表是 **1-based** ——
  `9 AIR_TEMPERATURE`、`11 SOLAR_RADIATION`（W/m²）、`12 SR_FLAG`；
  而 pandas `read_csv(sep=r"\s+")` 拿到的是 **0-based**（`8 / 10 / 11`）。
  原条目只写"列 8/10/11"、没标基准，按官方编号去核对会**错位一列**
- **缺测值随字段宽度不同**（官方 readme：*"the lowest possible integer for a given column format"*）：
  7 字符 1 位小数 → `-9999.0`；7 字符 3 位小数 → `-99.000`。
  实测同一文件（TX_Austin_33_NW，2022 全年）**两种形态同时存在**
  （`-99.000` 在土壤湿度列、`-9999.0` 在土壤温度列）⇒ **判缺测不能只查 `-9999`**
- 8 座德州站 × 8928 步（2022-07 全月），NSRDB 取最近像素同窗提取
- 结论：NSRDB 正午辐照比 USCRN **系统性高 ~10%**（1.067~1.188，卫星-地面已知水平差，
  被 ILR/损耗标定吸收）；**热浪期比值无额外漂移**（-1.4~-2.1%，在站间离散内）
  → 热浪低估是温度参数化问题，不是反演问题
- 脚本：`download_uscrn_tx_july2022.py`、`download_nsrdb_uscrn_pixels_july2022.py`、
  `verify_nsrdb_vs_uscrn_july2022.py`

### 3. 骤降事件归因（实际辐照底模）

- 判定：EIA 2h 内降幅 ≥1.5 GW 的事件，用**实际辐照底模**复算降幅，
  解释比 = 模型降幅/EIA 降幅 ≥0.95 → 云/辐照主导
- 2022-07 检出 7 个骤降事件，**解释比 0.95~2.88，全部云主导，无弃光信号**
- 注意 07-13（全月第二大缺口日）未入选：其傍晚为**渐进下降**（最大步长 ~1.3 GW/h）
  ——骤降口径看时间导数、缺口口径看对晴空的水平差，**两种口径互补**，缺一不可
- 脚本：`identify_pv_drop_events_2022-07.py`

### 4. 缺口→电价弹性标定（2025 标定，2026 复验）

- 缺口定义：`shortfall = 晴空包络 − 实际出力`；
  2025 年用**数据驱动包络**：每个 (hour, doy±15d) 网格取实际出力 P95
- 回归：`ln(RTM) ~ shortfall + wind + demand + 小时FE + 月份FE`（面板，RTM 5min→时均）
- **2025：β = +5.08 %/GW (SE 0.25)；高需求区 (≥72 GW) +5.84 (SE 0.44)**
- **2026 复验：+5.43 / +4.33 %/GW** → 两年一致 (±7%)，弹性结构稳定
- 光伏**水平** (-6.6%/GW) 与**爬坡** (-7.3%/GW) 为负控制项：电价对"缺口"远比对
  "水平"敏感，缺口才是价格冲击因子
- 单位换算坑：β(ln, per MW) → %/GW 需 **×100000**（1000 MW/GW × 100%）
- 脚本：`calibrate_price_elasticity_2025.py`；产物：data/ercot/price_elasticity_2025.csv

### 5. 2022-07 冲击推演（晴空反事实）

- 反事实 = pvlib `simplified_solis` 晴空辐照走 PS-021 同一物理链路
  （单轴跟踪/HRRR 温度/ILR 1.30/损耗 14%）
- **缺口校准必须逐小时偏移**：每小时的 (反事实−实际) 5% 分位作基准
  （-21~782 MW，正午 ~130-340、傍晚 ~730）。单一全局偏移会把傍晚低仰角下
  晴空模型对跟踪支架的系统性高估计入缺口 → 事件小时虚增 62→44、
  缺口总量虚高 43%；逐小时校准后晴日正午缺口中位仅 67 MW，与 2025 标定口径一致
- 结果：**44 个事件小时 → 17 个事件，缺口 100.3 GWh**（月光伏实发 2932 GWh 的 3.4%），
  中位缺口 2.06 GW、最大 4.40 GW（07-21）；
  上浮 = (exp(β·GW)−1)×100 → **中位 +11.0%、最大 +25.0%**
  （高需求弹性情景 +12.8%/+29.3%）；按 2022-07 ERCOT North 月均 $182/MWh
  （EIA Today in Energy #55139）折算中位 +$20、最大 +$46/MWh
- 热浪期 3 事件 25.6 GWh，07-13 傍晚云系 × 77.5 GW 需求 = 全月最强价格冲击 (+21.9%)；
  07-14 撒哈拉沙尘日 5h 事件 10.4 GWh（Solis 固定 AOD 0.1 → 沙尘日缺口为上界）
- 脚本：`pv_event_price_impact_2022-07.py`、`build_pv_event_price_report.py`

### 6. 关键陷阱（本次实证）

1. **pvlib 0.15.2 `simplified_solis` 数组输入返回 OrderedDict 而非 DataFrame**
   （`cs["dni"].values` 报 AttributeError）→ 用 `np.asarray(cs["dni"])` 取值
2. **晴空缺口校准必须逐小时**（见 §5）：傍晚跟踪 POA 系统性高估是伪缺口主源
3. **弹性标定与推演口径必须一致**：2025 用逐小时包络 → 2022 反事实也须逐小时偏移
   → **已由 PS-024 修复**：2025/2026 标定改用与 2022 同链路的物理晴空反事实；
   结论：弹性对口径不敏感（两口径 OLS 均值差 0.34 %/GW），但缺口量级差 1.3~1.7 倍
4. 2022-07 的 EIA-930 无 demand 字段 → 需求代理 = 全燃料出力之和
5. 上浮为条件均值而非尾部：RTM 稀缺定价 (>$1000) 不在 β 框架内；
   $ 锚为月均水平，仅作量级参考
   → **已由 PS-023 处理**：15 min 口径 + 分位数回归表明条件均值弹性（+5.08）高于任一分位，
   故本流程的极端场景上浮落在分位曲线上沿（**未低估**）；另 PS-023 推翻了本流程的
   "高需求区 +5.84" 结论（子样本法两年方向相反，稳健的交互项法为 +3.26/+4.48）
