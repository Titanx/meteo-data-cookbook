# 西班牙电力市场数据源调研（ESIOS / OMIE / PVGIS / ENTSO-E）

> 最后更新: 2026-09-29
> 功能: 调研西班牙电力市场与气象数据源，评估其作为 ERCOT「风光缺口 → 电价」链路（PS-021~028）**外部参照市场**的可行性与复刻路径
> 结论一句话: 西班牙是全球**最极端的高可再生渗透市场**（2025 风电 21.6% + 光伏 18.4%，负价/弃电常态化，弃电 1.6%→3.2%、2025-07 峰值 ~11%），是 PS-028「风电缺口 = 内生弃风」结论的**最强外部检验样本**；数据获取上 **OMIE 与 PVGIS 实测无需注册即可用**，**ESIOS 与 ENTSO-E 需邮件申请免费 token**（ESIOS 匿名 403）；但西班牙是**分区 + 日前为主的体系，无 ERCOT 式 RTM 实时价**，"缺口 → 实时尖峰"需改造口径

## 1. 背景与动机

PS-028 得到一个边界性结论：风电"潜力−实际"缺口与电价**负相关**，且控制风电水平后独立效应消失 ⇒ 它是**内生弃风的标记**而非价格上行成因。该结论的强度取决于样本中"弃风"的普遍程度——ERCOT 弃风虽存在但受数据可得性限制难以直接观测。西班牙提供了一个**弃电规模大到无法忽视**的市场，可用来做极端样本检验。

同时，用户提示关注 `esios.ree.es` 的 market-and-prices 页面（示例日期 2024-04-29）。

## 2. 实测验证（本流程全部结论均来自实际请求，非纯文献）

| 数据源 | 端点 | 认证 | 实测结果 | 判定 |
|---|---|---|---|---|
| **OMIE 日前市场文件** | `omie.es/es/file-download?parents=marginalpdbc&filename=marginalpdbc_YYYYMMDD.1` | 无 | **HTTP 200**；2024-04-29 取回 24 点，日均 **58.27 €/MWh**（与公开报道逐一吻合）；2026-09-27 取回 **96 点**（15min MTU），负价 2 段 | **可用，免注册** |

**技术要点**：OMIE 的 Market Time Unit 已由**小时改为 15 分钟**——2024 年文件 24 行、2026 年文件 96 行，解析器必须兼容两代格式（本次实测确认）。

## 3. 2024-04-29 当日（用户给定日期）

直接拉取 OMIE 原始文件（小时口径，24 点）：日均 **58.27 €/MWh**、最低 **35.00**（17h）、最高 **102.26**（08h）。

- 形态为**双峰 + 午间长平台**：08h 早高峰 102.26，22h 晚高峰 97.92，而 12~17h 连续 6 小时贴在全日最低 35.0 €/MWh —— 典型光伏压价的"鸭子曲线"。
- ⚠ **口径修正**：部分二手报道只称"晚高峰 97.9 为当日最高"，**与原始文件不符**（08 时段 102.26 才是最高）。应以 OMIE 原始文件为准；这也是本次坚持一手取数的价值。
- 背景：该日所在 2024 年 4 月全月日前均仅 **13.45 €/MWh**（2001 年以来最低月），4-29 因晚高峰叠加风光回落而显著反弹。

## 4. 西班牙市场关键事实（供外部参照用）

### 4.1 负电价常态化

| 时点 | 事实 | 口径 |
|---|---|---|
| 2024-04-01 | **首次负价**：15–18h 共 3h 为 −0.01 €/MWh；同日另有 10h 为 0，日均 2.76 | OMIE 日前 |
| 2024 全年 | **247 h 负价 + 537 h 零价 = 838 h（9.6%）**低于 1 €/MWh；另口径 244 h 负价 | 研究/二手 |
| 2025 全年 | **477 h 负价**（94 天），最低 −15.0；REE 口径 **798 h ≤0** | Electricity Maps / REE |
| 2026 Q1 | **347 h 负价**（占 Q1 时段 16%） | PV Magazine 汇总 |

### 4.2 弃电快速上升
- REE 半岛系统**技术受限（restricciones técnicas）**无法并网的可再生电量占比：**1.6%(2024) → 3.2%(2025)**。
- 2025 年 5–7 月弃电峰值 **7.2%**，**2025-07 约 11%（历史最高）**（2024-07 仅 0.8%）；2025-07 单月逾 **1,100 GWh** 未能并网。
- 2024 年维持电网的约束成本日均约 350 万欧元，极端日约 1,800 万欧元。

### 4.3 装机与结构（2025）
风电 **21.6%** 发电量（58,801 GWh，连续第三年第一）、核电 19%、光伏 **18.4%**（50,188 GWh，+12.5% YoY）。
年新增：光伏 8,100→9,500→10,105 MW（2023→2025），风电 650/1,300/1,150 MW。
口径警示：UNEF"约 23%"含自消费/消费口径，与 REE 发电量口径 **18.4%** 不可直接比较。

### 4.4 2025-04-28 伊比利亚大停电
12:33 CEST 西葡全境停电，ENTSO-E **ICS Scale 3**（欧洲 20 余年最严重），**史上首次过电压主导**。ENTSO-E 最终报告（2026-03-20）归因于多因素：400 kV 电压限值与脱网裕度过小、常规机组无功/电压支撑失效、境内出力快速下降与机组连锁脱网。
**对本项目的含义**：这是**系统安全（电压/无功）维度**的风险，与我们链路的**经济（价格）维度**是两回事，不可混用；但其高逆变器占比背景与"极端场景"研究（PS-027）相关。

## 5. ESIOS API 要点

- **认证**：`Authorization: Token token="<TOKEN>"`；token 由 `consultasios@ree.es` 邮件免费发放（网页内置公共 token 会变动，不可用于生产）。
- **Base URL**：`https://api.esios.ree.es`；端点 `/indicators`、`/indicators/{id}`、`search_indicators_by_name`、`/archives`。
- **参数**：`start_date`/`end_date`(ISO8601 带时区)、`geo_ids`、`geo_agg`、`geo_trunc`、`time_trunc`(five_minutes…hour/day/month/year)、`time_agg`。
- **响应**：JSON，`indicator.values[]` 含 `datetime`、`datetime_utc`、`value`、`geo_id`。

### 常用指标 ID（用前须以 `/indicators` 元数据复核）

| 指标 | ID | 备注 |
|---|---|---|
| 日前/现货电价（OMIE） | **600** | geo_id 3=España；多个第三方口径一致 |
| PVPC 2.0TD | **1001** | 次日价约 20:15 发布 |
| 实时需求 | **1293** | 半岛常配 geo 8741 |
| 实时光伏 | **1295** | 与光热 1294 分列 |
| 实时风电 | **551** | 水电 546 / 核电 549 / 联合循环 550 / 煤电 547 |

⚠ **geo_id 必须逐指标核验**：同一数字在不同指标下含义不同（indicator 600 的多地域列表与半岛系统 8741/8742/8743 不一致）。二手来源的 10033/10034/10035 = 需求/风电/光伏 **未获官方确认，标记未核实**。REE 另有"计划 PBF"与"实时 T.Real"两套口径，取数须区分。

### 5.1 token 已获得，但被域名级 WAF 拦截（2026-09-29 实测）

用户于 2026-09-29 获得个人 token（REE 邮件明确：仅供本人使用；公开项目须把数据落到自有服务器、不得让终端用户直连 REE；禁止大量/冗余/重复请求）。实测**仍不可用**，且原因**不是 token**：

- `api.esios.ree.es`、`www.esios.ree.es`、`www.ree.es`、`apidatos.ree.es` **全部 403**，返回同一张 **Imperva/Incapsula** 拦截页（`X-Iinfo`、`visid_incap_*` cookie、`_Incapsula_Resource` 脚本）；**带 token 与不带 token、连根路径都一样** ⇒ 拦在鉴权之前。
- **有界面真实浏览器（Playwright Chromium）同样 403**；`curl_cffi` 的 Chrome/Safari/Edge **TLS 指纹伪装**也全部 403 ⇒ 非指纹、非无头检测，属**域名级/出口 IP 级**封锁。
- 同机对照：OMIE / Energy-Charts / PVGIS / Open-Meteo / ENTSO-E 门户 **均 200** ⇒ 只有 `*.ree.es` 被挡。

**处置**：换到可访问 `ree.es` 的网络运行，或设 `ESIOS_PROXY`（脚本已支持）；在此之前，西班牙链路继续用 **Energy-Charts + OMIE + Open-Meteo Seasonal** 推进（PS-030/031/035 即如此）。完整证据见 [PF-013]。

## 6. 复刻路径（ERCOT → 西班牙）与结构性差异

| ERCOT 元件 | 西班牙替代 | 门槛 |
|---|---|---|
| NSRDB 辐照 | **PVGIS-SARAH3**（逐小时, 2005–2023, 免注册）/ **SARAH-3** 原生（0.05°, 30min, 1983–）/ **CAMS Radiation**（1–60min, 2004–, 100 请求/日）/ ERA5(-Land) | PVGIS 无；CAMS 需 ADS 账号 |
| pvlib 出力建模 | 不变（pvlib 通用） | 无 |
| GEM 电站清单 | GEM 全球风光追踪库**覆盖西班牙**（公用事业风电约 26.8 GW 运营） | 本地已有 |
| EIA-930 实际分技术出力 | **ESIOS**（高频、西班牙口径）+ **ENTSO-E**（标准化、可回溯校验） | 均需邮件 token |
| 电价 | **OMIE**（源头，已实测）/ ESIOS 600 / ENTSO-E 日前价 | OMIE 无 |

**关键结构性差异**：ERCOT 是**节点定价 + 实时市场（RTM）**，我们链路的"缺口 → 实时价冲击"依赖 RTM；西班牙/伊比利亚是**分区定价 + 日前为主 + 日内连续交易 + 平衡市场**，**无 ERCOT 式 5 分钟实时结算价** ⇒ "缺口 → 实时尖峰"推演必须改造口径（改用日前价或日内连续价），**不可直接平移**。

## 7. 结论与下一步

1. **零门槛先做**：OMIE（价）+ PVGIS（辐照）+ GEM（清单，已有）即可搭"西班牙版最小链路"，把 PS-021 的 pvlib 建模搬到西班牙，与 ENTSO-E/ESIOS 实际光伏出力对照。
2. **token 进展与替代**：ESIOS **已申请到个人 token（2026-09-29）**，但受 REE **域名级 WAF 封锁**（[PF-013]），本机不可直连 ⇒ 换网络/设代理后即可用（脚本已就绪：`download_spain_esios.py`，代理可感知 + 按月续传；连通性自检 `test_esios_api.py`）。ENTSO-E（`transparency@entsoe.eu`）**本机可达**，可作 ESIOS 的替代解锁路径（标准化、可回溯），仍待申请。
3. **优先验证目标**：PS-028 的"缺口 = 内生弃风"在**弃电 11% 的极端样本**上是否更强（即"高可再生出力 + 低需求 → 负价 → 弃电"的负相关是否比 ERCOT 更显著）——这是对现有结论最强的外部检验。
4. **谨慎处理**：2025-04-28 大停电等系统事件会打断时序连续性，缺口统计须剔除；MTU 由小时转 15min（约 2025-10）拼接须对齐时点。

## 8. 局限与未决

- ESIOS 官方公开页未见**量化速率限制**条款，未核实；不应把第三方（datons/python-esios）限流当官方限制。
- 指标 ID 冲突（10033/10034/10035 未确认；1001 在个别资料被误标为"日前边际价"）。
- 各指标**历史起点不统一**，官方未给统一起始年。
- 负价小时数**口径分歧大**（2025 年 477 vs 798 h）：是否含零价/日内/半小时计量不同，引用须标口径。
- **PVGIS 止于 2023**（SARAH-3 版），近两年需 CAMS 或 SARAH-3 ICDR 补足。
- ENTSO-E 自 2025 起新增 File Library，鉴权改 Keycloak token，与旧 REST token 不同。
