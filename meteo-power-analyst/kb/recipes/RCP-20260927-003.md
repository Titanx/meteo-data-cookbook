# WMO S2S 数据库获取路径（ECDS，多中心延伸期回算）

> **类型**: process
> **成熟度**: draft（门户可达性与结构已验证，数据获取需注册后实测）
> **创建时间**: 2026-09-27
> **最后引用**: 2026-09-27
> **标签**: s2s, wmo, subseasonal, reforecast, hindcast, ecds, ecmwf, ensemble, multi-model, lead-time, verification, openmeteo, ercot
> **适用阶段**: architect, implement

## 背景

PS-017 用 Open-Meteo（EC46/SEAS5）完成了 45 天延伸期预报的**单窗口**精度核验，但存在结构性局限：EC46 历史归档仅保留最近一个月的 51 成员（窗口前 5 天 lead 缺测），无法做多初始化、多窗口的稳健重采样。WMO S2S 数据库提供 13 个业务中心的多模式集合回算（reforecast/hindcast），是延伸期预报检验的标准数据集，可把 PS-017 的核验从"单窗口"升级为"多年回算统计"。

## 内容

### 1. 数据集概况

- **全名**: S2S global sub-seasonal to seasonal ensemble (re)forecasts，WMO WWRP + WCRP 联合 S2S 项目（2013 启动）
- **生产中心**: 13 个 NWP/研究机构——ECMWF、ECCC（加拿大）、NOAA/NCEP（美国）、KMA（韩国）、JMA（日本）、CMA（中国）、HMCR（俄罗斯）、BoM（澳大利亚）、Météo-France、UKMO、CNR/ISAC、CPTEC（巴西）等
- **预报时效**: 各中心 34~65 天（ECMWF 46 天、NCEP 44 天等）
- **实时预报存档**: 2015 年起
- **回算 (reforecast)**: 各中心起始年不同（多数 1981/1996/2000 起），分两类——**fixed**（固定一组回算）与 **on-the-fly**（随实时模式版本滚动生成），取决于中心
- **变量**: 10 m 风、2 m 温度、降水、位势高度、SSR 等（各中心不等）
- **用途定位**: 与 PS-017 的 Open-Meteo 渠道互补——Open-Meteo 免注册适合快速业务获取，S2S 库适合统计检验与多模式对比

### 2. 访问路径（2026-04-21 起 ECDS）

| 项目 | 说明 |
|------|------|
| 门户 | `https://ecds.ecmwf.int/datasets/s2s-forecasts`（实时预报）、`.../s2s-reforecasts`（回算） |
| 实测可达性 | 门户与 `ecds.ecmwf.int/api/catalog/v1/collections` 均 HTTP 200（2026-09-27，中国网络直连可用） |
| 认证 | 需注册 ECMWF 账号（免费），个人页生成 API key |
| API 风格 | 2026-04-21 S2S 从旧 WEB-API 迁移至 ECMWF Data Store (ECDS)，新接口为 CDS-API 风格 + OGC processes 端点 `api/retrieve/v1/processes/s2s-reforecasts`；过渡期新旧并行 |
| 数据格式 | GRIB2 为主 |

### 3. 获取流程（待注册后实测）

```
1. 注册 ECMWF 账号 (ecds.ecmwf.int) 并获取 API key
2. 配置凭证 (~/.ecdsapirc 或环境变量, 参照 ECDS 官方文档; 凭证管理遵循 GL-009)
3. 选择中心 + 变量 + 区域 (ERCOT 25.8~36.5N, 106.7~93.4W) + 回算窗口
4. 提交异步检索任务 (S2S 库按请求切子集, 避免全量下载)
5. GRIB2 → cfgrib 读取 → 与 PS-017 同口径逐 lead 误差统计
```

### 4. 与 PS-017 的衔接

- PS-017 核验链路（ERA5 基准 / 逐 lead MAE / GFS 对照）可直接复用，S2S 库将单窗口序列扩展为多年回算集合统计
- 推荐优先中心：**ECMWF**（与 EC46 同源，量纲可比）与 **NCEP**（与 GFS 同源，可验证 GFS 延伸期能力）；CMA 可作东亚业务对照
- 建议核验设计：对 ERCOT 6 站，取每中心 ≥20 个初始化日期的回算，按 lead 1~45 聚合 MAE/RMSE + 集合离散度置信带

### 6. 注意事项

- **注册前不可下数据**：与 IMERG（netrc 认证即用）不同，S2S 需要先在 ECDS 完成注册流程
- 旧 WEB-API（`apps.ecmwf.int`）过渡期结束后将失效，新代码直接面向 ECDS API
- 回算有 fixed/on-the-fly 之别，跨中心对比时注意模式版本一致性；on-the-fly 回算与实时预报同版本（更可比），fixed 回算年代长但版本冻结
- 全量 S2S 体量极大（PB 级），**务必按区域/变量/lead 切子集请求**
- 引用来源：ECDS S2S 数据集页（13 centers、two datasets、fixed/on-the-fly）与 ECMWF S2S 项目页（up to 60 days、11 operational centres 存档口径）[$TRAE_REF](https://ecds.ecmwf.int/datasets/s2s-forecasts?tab=overview)[$TRAE_REF](https://www.ecmwf.int/en/research/projects/s2s)
