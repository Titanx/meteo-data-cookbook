# AEMO NEMWEB 澳洲电力市场数据下载与 MMS 解析对账流程（UIGF 官方预测 vs SCADA 实测）

> 成熟度: **verified**（2026-11-02 实跑：2026-09 整月 32/32 文件 61 MB 校验通过；UIGF vs SCADA 对账 1 829 946 行匹配 99.4%，覆盖 213 场站）
> 适用场景: 澳洲 NEM 市场的场站级出力预测对账、负电价/弃电分析。**全程匿名免注册**，curl 可遍历，中国网络直连可达。WEM（西澳）另有独立数据页，本流程未覆盖。

## 0. 结论速览

- NEMWEB（www.nemweb.com.au）是**全球最容易程序化获取的电力市场数据之一**：Apache autoindex + 月度 zip 归档，无登录无 token 无反爬。
- 三层数据全公开：官方无约束预测（UIGF）、5 分钟全场站实测（Dispatch_SCADA）、区域电价（Public_Prices）——文章/商业团队做"对账"的数据底座任何人都能复现。
- 数据格式是 MMS（zip 套 zip + `I/D` 行），**两个致命坑**：字符串字段带双引号必须剥除；表名/字段名与直觉不同（实测表是 `UNIT_SCADA` 不是 `DISPATCH_UNIT_SCADA`，时间字段是 `SETTLEMENTDATE` 不是 `INTERVAL_DATETIME`）。
- 2026-09 实测：UIGF 系统性高估（bias +7.09 MW，+21%），SA1 正午负电价时段占比 29.8%、TAS1 触及 −1000 AUD/MWh 地板价。

## 1. 数据通道与 URL 模式

```
# 按报表族 × 月归档（推荐，匿名）
https://www.nemweb.com.au/REPORTS/ARCHIVE/{REPORT_FAMILY}/PUBLIC_<...>_YYYYMM01.zip
# 实测三件套:
#   Next_Day_Intermittent_Gen_Scada/PUBLIC_NEXT_DAY_INTERMITTENT_GEN_SCADA_20260901.zip  (17.5 MB 月包)
#   Dispatch_SCADA/PUBLIC_DISPATCHSCADA_YYYYMMDD.zip                                     (1.2 MB/日包)
#   Public_Prices/PUBLIC_PRICES_20260901.zip                                             (7.8 MB 月包)

# 2009 起全量深度归档（MMSDM，含全部 MMS 表）
https://www.nemweb.com.au/Data_Archive/Wholesale_Electricity/MMSDM/YYYY/MMSDM_YYYY_MM/
```

- 目录页是 Apache autoindex，先 `curl` 目录页摸清文件命名再批量下。
- Dispatch_SCADA 归档按**日**包；UIGF 与 Prices 有**月**包（内套日包）。
- 下大文件前可 HEAD 探大小，下载后做字节精确校验（同 `PIT-20261002-001` 纪律）。

## 2. 并发下载模板（ThreadPoolExecutor + 完整性校验）

```python
import subprocess, zipfile
from concurrent.futures import ThreadPoolExecutor

def fetch(url, out):
    if out.exists() and zipfile.is_zipfile(out):
        return "skip"
    subprocess.run(["curl.exe", "-sS", "-o", str(out), url], check=True)
    assert zipfile.ZipFile(out).testzip() is None  # CRC 校验
    return "ok"

with ThreadPoolExecutor(4) as ex:
    list(ex.map(lambda a: fetch(*a), jobs))
```

- 4 并发下 61 MB 约 1 分钟，无 429/限流；已存在文件跳过可断点续跑。

## 3. MMS 格式解析（核心解析器，双引号坑在此修）

MMS 结构：zip 套 zip（月包→日包→CSV）；行前缀 `C,`=元数据、`I,`=字段定义（第 5 列起为字段名）、`D,`=数据行（第 5 列起为值）；表名 = `I,` 后三列（如 `I,DISPATCH,UNIT_SCADA,1`）。

```python
def read_mms_zip(zip_path, table_filter=None, keep_fields=None):
    """动态按 I 行映射 D 行; table_filter 匹配表名子串."""
    frames = []
    zm = zipfile.ZipFile(zip_path)
    for day_name in [n for n in zm.namelist() if n.lower().endswith(".zip")]:
        zd = zipfile.ZipFile(io.BytesIO(zm.read(day_name)))
        for csv_name in [n for n in zd.namelist() if n.lower().endswith((".csv", ".txt"))]:
            txt = io.TextIOWrapper(io.BytesIO(zd.read(csv_name)), encoding="utf-8", errors="replace")
            header, rows = None, []
            for ln in txt:
                p = ln.rstrip("\r\n").split(",")
                if len(p) < 5: continue
                tbl = ",".join(p[1:4])
                if table_filter and table_filter not in tbl: continue
                if p[0] == "I":
                    header = p[4:]
                elif p[0] == "D" and header is not None:
                    vals = [v.strip().strip('"') for v in p[4:]]   # ★ MMS 字符串字段带双引号, 必须剥
                    rows.append((vals + [""] * len(header))[:len(header)])
            if rows and header:
                frames.append(pd.DataFrame(rows, columns=header)[keep_fields])
    return pd.concat(frames, ignore_index=True) if frames else pd.DataFrame()
```

- **★ 双引号坑**：MMS 字符串字段带双引号（`"2026/09/01 04:05:00"`），裸 split 后 `pd.to_datetime` 全 NaN → dropna 静默清空 → 下游 `isin` 匹配全为 0。症状是"解析 0 行/匹配 0%"，先查引号。
- 时间解析：`pd.to_datetime(col, format="%Y/%m/%d %H:%M:%S")`；市场时间是 **AEST（UTC+10，无夏令时）**，与其他市场对齐时注意。

## 4. 表名与字段速查（实测验证）

| 用途 | 表名 | 关键字段 | 坑 |
|------|------|----------|-----|
| 官方无约束预测（UIGF） | `NEXT_DAY_INTERMITTENT_GEN_SCADA` | RUN_DATETIME, DUID, SCADA_TYPE, SCADA_VALUE | **对账基准只取 `SCADA_TYPE=='ELAV'`**（无约束可用能量预测）；LOCL 是本地口径 |
| 场站实测出力 | `UNIT_SCADA`（报表 DISPATCH_SCADA） | SETTLEMENTDATE, DUID, SCADAVALUE | 表名**不是** `DISPATCH_UNIT_SCADA`；时间字段**不是** `INTERVAL_DATETIME` |
| 区域电价 | `DREGION`（报表 DISPATCHPRICE） | SETTLEMENTDATE, REGIONID, RRP, TOTALDEMAND | RRP 为 5 分钟价；负价 = RRP<0，−1000 是市场地板价 |

- 不确定表名/字段时，先解包一个日包 grep `I,` 行看字段定义，别猜。
- 深度归档（MMSDM）里有全量表结构文档 MMS Data Model，权威定义在 AEMO 官网。

## 5. 对账口径（UIGF ELAV vs SCADA）

1. 两表按 `(时间戳, DUID)` merge（时间戳分别取 RUN_DATETIME / SETTLEMENTDATE）。
2. NMAE = MAE / obs_mean（文章同款口径）；bias = pred − obs。
3. 风/光分类启发式（DUID 无技术元数据时）：按场站小时均值算**夜间(0–4,22–23时)/日间出力比**，<0.15 判光伏、>0.5 判风电、其余 other。注意 pivot 后的小时索引是 int 非 DatetimeIndex，用 `np.asarray(g.index)` 再取夜窗。

**2026-09 实测结果**（203 万对账行，213 场站：光伏 120 / 风电 93）：

| 指标 | 光伏 | 风电 |
|------|------|------|
| NMAE 中位数 | 1.16 | 0.77 |
| bias 中位数 | +6.86 MW | −5.51 MW |
| r 中位数 | 0.61 | 0.13 |

- 系统级 bias **+7.09 MW**（pred_mean 40.1 vs obs_mean 33.0，+21%）：UIGF 高估 = 预报误差 + 弃电/限电"报满发"。
- **口径警示**：本对账测的是"官方无约束预测 vs 实际出力"的偏离（含弃电），**不能直接对标**商业团队"第三方模型 vs UIGF"的 NMAE（其光伏 20.5%/风电 12.2%）；风电 r_median 0.13 极低是次日 ELAV 可用性预报平坦性所致。两种口径都成立，混用会得出荒谬结论。

## 6. 负电价统计口径（Public_Prices）

按 REGIONID 分组：负价占比 = RRP<0 行数 / 总行数（5 分钟粒度）。2026-09 实测：

| 州 | 负价占比 | 最低价 |
|----|---------|--------|
| SA1 | **29.8%** | −294.71 |
| VIC1 | 23.4% | −68.98 |
| TAS1 | 21.1% | **−1000.0（地板价）** |
| QLD1 | 16.7% | −245.64 |
| NSW1 | 10.4% | −18.51 |

- 近 1/3 时间负价（SA1）与"澳洲弃电率全球最高"互证；负价时段 = 储能套利/需求响应信号。
- 更细的价格工具：Trading_Cumulative_Price 报表族（30 分钟结算价累计）。
