# 国家青藏高原科学数据中心（TPDC）数据集下载流程（HTTPS 在线通道 + FTP 大文件通道）

> 成熟度: **verified**（2026-10-30 实跑：HCD01 README 2358 B、mask 9 861 B、前代数据集 RH.rar 52 148 628 B、WS.rar 55 434 912 B，4/4 字节精确匹配）
> 适用场景: 需要中国区格点/站点气象数据（HCD01、CMFD、前代格点集等 TPDC 开放获取数据集）时走本流程。免注册。

## 0. 结论速览

- TPDC（data.tpdc.ac.cn）是 Vue SPA + JSON API，**开放获取数据集无需登录**即可程序化下载。
- **<1 GB 文件走 HTTPS**（`batchDownloadByFileId`，POST 返回二进制流）；**>1 GB 只走 FTP**（凭据页面公开，但 FTP 端口对海外/代理出口常不可达，需大陆直连网络）。
- 先用文件树 API 摸清结构再决定通道：若数据集把多年数据打成大 zip（如 HCD01 的 7 个 12–15 GB zip），即使只想要单年也只能 FTP。

## 1. 元数据与文件树 API（全部免 token）

```
# 附件清单（README 等）
GET  https://data.tpdc.ac.cn/view/metadataView/getDocumentList?metadataId=<uuid>

# 根文件树 / 子目录（type=dir 则继续用 getFileDataList 下钻）
GET  https://data.tpdc.ac.cn/file/file/getRootFileDataList?metadataId=<uuid>
GET  https://data.tpdc.ac.cn/file/file/getFileDataList?parentId=<fileId>

# 附件下载（README 等文档类，fileKey=3）
POST https://data.tpdc.ac.cn/file/file/downloadFile?fileId=<id>&fileKey=3

# 数据文件在线下载（<1GB，返回 application/octet-stream）
POST https://data.tpdc.ac.cn/file/file/batchDownloadByFileId?fileId=<fileId>

# FTP 凭据（页面"下载"面板同源）
POST https://data.tpdc.ac.cn/file/ftp/downLoadFtpUser?metadataId=<uuid>
```

- `<uuid>` = 数据集页面 URL 末段（如 HCD01 `01bbff40-641d-410d-a8de-1e39c7d7200b`）。
- 响应中每个文件有 `id`、`size`、`type`（dir/file）、`path`——**用 `size` 做下载后字节校验**。

## 2. 下载与校验

```python
import requests
r = requests.post(f"https://data.tpdc.ac.cn/file/file/batchDownloadByFileId?fileId={fid}", timeout=600)
assert r.status_code == 200 and len(r.content) == declared_size
open(out_path, "wb").write(r.content)
```

- 校验字节数必须做（防 IncompleteRead，同 `PIT-20261002-001`）。
- rar/zip 用本机 WinRAR UnRAR 解压（`"C:\Program Files\WinRAR\UnRAR.exe" x -y <rar> <dir>\`）。

## 3. FTP 大文件通道（>1 GB）

1. 浏览器打开数据集页面 → 点"下载" → 面板给出 `ftp2/ftp3.tpdc.ac.cn` + 当次有效的账号/密码（每次访问会变，脚本化前需现取）。
2. 命令行直下：
   ```
   curl -o out.zip "ftp://<user>:<pass>@ftp2.tpdc.ac.cn/<uuid>/HCD01/<file>.zip"
   ```
3. ⚠️ 本机若经代理/海外出口，TCP 21 常被 TPDC 侧静默丢弃（SYN 无响应超时；对照 ftp.gnu.org:21 可通以排除本机拦截）。**需大陆直连网络**。

## 原理与坑

> 引用知识（kb/）:
> - `[PIT-20261002-001]` 大响应 IncompleteRead——字节校验是唯一防线
> - 单前缀（file 服务路径只写一层）会 404：SPA 的 enclosure axios baseURL 已是 file 服务前缀，且调用串自带同一前缀 ⇒ 真实路径是 **双层 file 前缀**（从 `app.<hash>.js` 里 grep `enclosureAxios` 可验证）
> - `batchDownloadByFileId` 对 >1 GB 文件返回 HTTP 500（无 message），不是超时而是服务端拒绝——别浪费重试
> - IEM METAR 大请求（单站 39 年）同样会被掐断：改分段（按 10 年段/按年）稳定，见 `RCP-20261016-001`
