# 光伏缺口的持续时间维度建模（2025/2026 ERCOT，物理晴空反事实口径）

> 最后更新: 2026-09-28
> 功能: 检验「连续多小时缺口是否带来超额电价传导（持续时间溢价）」，并刻画恶劣缺口的事件时长与日际持久性结构
> 结论一句话: **多小时持续是常态（≥3h 承载 92% 恶劣缺口能量、事件可填满整个白天至 11h；日级连阴最长 25~26 天），但「持续时间溢价」证据薄弱且跨年不稳健（2025 有、2026 无）⇒ 逐小时线性的弹性×缺口外推未因「时间维度」低估，佐证 PS-023/024。**

## 1. 背景与问题

PS-022/023/024 的弹性是按【小时】标定（+5.3 %/GW），2022-07 事件推演把 44 个事件小时当独立样本逐小时叠加。遗留问题：
- 恶劣缺口在连续小时内**持续多久**（单发 vs 长云系）？
- 扣掉瞬时缺口量级后，已持续数小时的缺口是否比刚发生的同量级缺口传导**更高电价**（储备耗竭/持续爬坡/系统收紧 = 时间维度的凸性）？

若存在强正的持续时间溢价，则逐小时线性外推会**低估**长时间缺口的累计冲击 —— 需要检验。

## 2. 数据与事件口径

- 数据: data/ercot/shortfall_physical_2025_2026.csv（物理晴空反事实缺口，白天小时，2025-01 ~ 2026-09，7949 h）
- 功率/电价: `ercot_rtm_HB_HOUSTON_2025-01-01_2026-09-07.csv`（15min）做分位对齐
- **事件定义**: 物理缺口 ≥ **12 GW**（≈ 舰队 30.89 GW 的 39% 容量离线）的连续白天小时
  - 阈值理由: 类比 PS-022(2022, 舰队 10.66 GW, 事件峰值 4.4 GW) 按舰队规模放大 30.89/10.66 ≈ 2.9× → 4.4×2.9 ≈ 12.7 GW
  - 注意: 物理口径缺口中位已达 **5.5 GW**（30GW 舰队下日常部分云况即数 GW 缺口），事件是「远低于晴空/典型的恶劣时段」

## 3. 主要结果

### 3.1 白天内事件时长结构（稳健）

| 指标 | 值 |
|---|---|
| 恶劣缺口事件数 (≥12GW) | 298 个 |
| ≥2h 能量占比 | 98% |
| ≥3h 能量占比 | **92%** |
| ≥4h 能量占比 | 85% |
| 单发 1h 事件占比 | 仅 16%（能量占比小） |
| 最长连续缺口 | 11 h（填满整个白天 13–23 UTC） |
| 单日最大能量缺口 | 286 GWh（2026-05-01） |

⇒ **真实恶劣缺口是「覆盖舰队大片区域、持续大半个白天」的云系事件，而非小时孤立尖峰。**

### 3.2 白天内持续时间溢价（跨年不稳健）

模型: ln(RTM) ~ sf(GW) + [cum_gwh | hours_into] + wind + dem + C(hour) + C(month)，小时粒度 OLS + HAC。

| 2025 / 2026 | sf 弹性 %/GW | cum 系数 %/GWh | hours_into |
|---|---|---|---|
| 基线（只含 sf） | +5.05 / +6.15 | — | — |
| + cum | +4.12 / +5.65 | **+0.198(SE.07) / +0.101(SE.06)** | — |
| + hours_into | +4.31 / +5.73 | — | +3.50 / +2.08 (SE 1.3/1.2) |
| + cum + hours | +4.07 / +5.75 | +0.27 / +0.01 | −1.35 / +1.90 (SE>4) |

- cum 与 hours_into **高度共线**（事件内累积能量 ≈ 时长×均值缺口），单独进入各显著、同时进入均不显著
- **权威证据: 事件内位置残差**（控制瞬时 sf 与小时/月 FE 后，基线模型残差按事件第 N 小时取均值）
  - 2025: 第1h −0.041 → 第5h +0.052（**单调上升**，5h 相差 ≈ +9%）
  - 2026: +0.037 → −0.059 → −0.028 → −0.030 → +0.017（**无单调**）
- ⇒ 持续时间溢价在 **2025 显著、2026 不显**著 ⇒ **跨年不稳健**

### 3.3 尾部 Q99 累积（跨年不稳健）

15min 对齐 QuantReg，cum 溢价 %/GWh：
- 2025: Q50 −0.03 / Q90 +0.03 / **Q99 +0.38(SE.035)**
- 2026: Q50 +0.10 / Q90 +0.08 / Q99 −0.06(SE.04)

⇒ 仅 2025 的 Q99 显示显著正累积；2026 无。尾部累积同样跨年不稳健。

### 3.4 日际持久性：周级连阴云系（稳健）

- 逐日能量缺口（>50MW 小时求和），高缺日阈 = 全样本日值中位（84.5 GWh）
- 连续高缺日 run 长度分布: 1d×19, 2d×17, 3d×10, 4d×5, 5d×2, 6d×5, 7d×3, 9d×3, 11d×4, **15d×1, 25d×1, 26d×1**
- ⇒ 高缺日高度聚簇，低日照不是孤立天而是**持续数周的天气/气候型**（春季锋面滞留、热盖云层等）。指向储能容量/多日备用充足性（非电价冲击）。

## 4. 结论

| 维度 | 结论 | 稳健性 |
|---|---|---|
| 白天内持续 | 恶劣缺口多小时持续常态，≥3h 承 92% 能量，事件可填满整个白天 (11h) | **稳健** |
| 持续时间溢价 | 二阶小幅加价，2025 显著(+5%/第5h)、2026 无 | **不稳健** |
| 尾部 Q99 累积 | 仅 2025 显著 (+0.38 %/GWh) | **不稳健** |
| 日际持久性 | 连阴最长 25~26 天，多日聚簇 | **稳健** |
| 对前序影响 | 逐小时弹性×缺口外推**未低估**（时间维度） | 强化 PS-023/024 |

**核心抵销结论**: 每小时缺口本身已承载价格水平，持续时间只带来二阶、跨年不稳健的小幅加价。**逐小时线性外推在时间维度上是未低估的**，与 PS-023「条件均值弹性 +5.08 高于任一分位、尾部不放大」、PS-024「弹性对口径不敏感」相互印证，构成连锁稳健性的第三重证据。

## 5. 陷阱与口径

1. **事件阈值是固定 12 GW**，随装机增长应重新缩放（按舰队容量比例）；2026 装机清单不全（缺 ~4GW）会轻微影响阈值语义
2. **cum 系数 %/GWh 不能线性外推到整日 250 GWh**（共线性会夸大至 +50%），权威证据取「事件内位置残差」这种同量级、控制时段的非参数对比
3. **hours_into/cum 非事件小时置 0**：系数混合了「进入事件」与「持续加深」两个成分；工程上可接受但解释要谨慎
4. **物理口径缺口中位 5.5 GW** —— 多数白天本身在晴空反事实之下数 GW，报缺口必须声明是「相对晴空/典型」的恶劣时段
5. 事件残差按小时序号分桶有共线性（长事件多落傍晚需求峰），但模型已含小时 FE，故是「同时刻、同量级」的可比对比

## 6. 后续方向

- 日际/周际持久性对**储能充足性与多日备用**的含义（非电价视角，接储能扩张 PS 待建）
- 结合季节预报 (PS-017/PS-020) 做「连阴云系」的先验概率化
- 2026 装机清单补全后重缩放事件阈值，复核持续时间溢价的可复制性
