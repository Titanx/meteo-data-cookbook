# 缺口"工况指纹"：外生 vs 内生（ERCOT × 西班牙）

> 最后更新: 2026-09-29
> 功能: 把 PS-032 的回归符号落到**可观测工况**上——按缺口分位分组，比较各组的小时价格中位、低价/负价频率、需求（负荷）中位与时段，检验"内生缺口 = 供给过剩标记"这一**机制本身**是否成立
> 结论一句话: **内生缺口（潜力−实际）是货真价实的"供给过剩标记"** —— ERCOT 光伏最高两档缺口小时负价频率 **0.0% → 16.0%**（需求同向下降 60.5 → 51.7 GW）、风电 **0.7% → 5.5%**、西班牙光伏 2025 达 **33.4%**；而**外生缺口不含过剩信号**：ERCOT 风电低风异常高的小时负价频率反而 **6.4% → 0.1%**、价格中位上升（真稀缺），ERCOT 光伏晴空缺口两年无稳定标记（corr −0.06/+0.02）

## 1. 背景

PS-032 证明"外生缺口→正、内生缺口→负"只是**方向相容**，且仅"内生→负"经得起控制出力水平。但那只回答了"符号是否稳健"，没回答"机制是否真实"：内生缺口高的小时，**是不是真的**处在低需求、低价/负价的过剩工况？本流程用与 PS-028/PS-031 同源的分位分组法，把符号读成工况指纹。

## 2. 数据与方法

| 元素 | 来源 | 说明 |
|---|---|---|
| ERCOT 面板 | `ercot_hourly_panel_{2025,2026}.csv` | RTM(小时均) + EIA-930 光伏/风电/需求 |
| ERCOT 光伏两口径 | `ercot_pv_potential_2025_2026.csv`（内生）、`pv_clearsky_hourly_2025_2026.csv`（外生） | 同 PS-032 |
| ERCOT 风电两口径 | `wind_power_hourly_2025_2026.csv` | `w_short`（内生）/ `w_drought`（外生） |
| 西班牙光伏两口径 | `spain_regime_hourly_{2023,2024,2025}.csv` | `gap_cs`（外生）/ `gap_w`（内生） |

**方法**：对每个"市场×技术×成因"指纹，把样本按缺口值做**等样本十分位**分组（`rank(method="first")` 保 10 档均衡，避免零值堆叠导致 qcut 塌缩），逐档统计：小时价格中位、低价频率（<5 本币）、负价频率（<0）、需求/负荷中位、时段中位；并取"最低两档 vs 最高两档"作对照。
样本：ERCOT 光伏取白天（solar>50）、风电取全时段；西班牙取白天（act>50）。

## 3. ERCOT 结果（2025/2026 均值）

| 指纹 | 低价频率 低→高 | 负价频率 低→高 | 价格中位 低→高 | 需求中位 低→高 (GW) | corr(缺口,价格) |
|---|---|---|---|---|---|
| 光伏·外生（晴空） | 5.7% → 5.0% | 1.0% → 3.3% | 28.3 → 26.5 | 53.6 → 55.2 | −0.02 |
| **光伏·内生（潜力−实际）** | 1.1% → **25.2%** | 0.0% → **16.0%** | 27.6 → 20.5 | **60.5 → 51.7** | −0.16 |
| **风电·外生（低风异常）** | 10.2% → **2.0%** | 6.4% → **0.1%** | 21.2 → **34.3** | 50.5 → 52.1 | **+0.25** |
| 风电·内生（潜力−实际） | 1.7% → 9.0% | 0.7% → 5.5% | 26.4 → 24.6 | 58.0 → 51.8 | +0.00 |

- **两个"内生"指纹都是过剩标记**：高缺口档负价频率显著抬升（光伏 0→16.0%、风电 0.7→5.5%），且**需求中位同向下降**（光伏 60.5→51.7 GW）。
- **风电"外生"是被"稀缺"而非"过剩"标记**：低风异常高的小时负价频率从 6.4% 掉到 0.1%，价格中位 21.2→34.3 $/MWh，corr **+0.25/+0.26** —— 与"外生供给损失→推高电价"一致。
- **光伏"外生"（晴空缺口）两年不稳定**（corr −0.06/+0.02，负价档位方向不一致）⇒ 与 PS-032「外生正号不稳健」互相印证：该量的符号不可靠。

## 4. 西班牙时间截面（高缺口档负价频率）

| 年 | 外生缺口（高档） | 内生缺口（高档） |
|---|---|---|
| 2023（全年零负价） | 0.0% | 0.0% |
| 2024（负价 247 h） | 12.0% | 15.7% |
| 2025（负价 544 h） | 26.9% | **33.4%** |

西班牙内生缺口高值档的负价频率 **0% (2023) → 15.7% (2024) → 33.4% (2025)**，与负价小时数 0→247→544 同步 ⇒ **同一技术跨年份，随弃电普及，"内生缺口=过剩"的标记逐年增强**，部分回应了 PS-032「无法做时间向可逆性检验」的缺口。

## 5. 结论

1. **机制坐实**：内生缺口高的时段 = 低需求 + 负价/低价高发，两个市场、两种电源一致 ⇒ "内生缺口 = 供给过剩标记"不只是回归符号。
2. **对照有区分度**：风电低风异常（外生）高的小时负价更少、价格更高，是稀缺 ⇒ "外生/内生"二分在机制上确有区分。
3. **随市场成熟增强**：西班牙 2023→2025 的负价频率随年份抬升，说明该标记的强度取决于弃电/负价的普及度，而非电源类型。

## 6. 局限

1. ERCOT 光伏**外生**缺口（晴空）受太阳高度角/季节主导，不是干净的云量代理，两年不稳定。
2. ERCOT 光伏**内生**缺口含约 23% 模型残差（ERCOT 实际弃光仅数个百分点），档位含噪声。
3. 分组为**等样本十分位**，跨市场/跨指纹的档位**不可直接比大小**（只比同指纹内的低档→高档变化）。
4. 西班牙仍用**日前价**；ERCOT 价格用小时均（15min 有更极端值）。
5. 未做统计显著性；频率差异未给置信区间。
