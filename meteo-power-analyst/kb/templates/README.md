# templates/ — 条目空白模板

拷走使用，替换所有 `<占位符>`。占位符形式（含 `<`、`YYYYMMDD`）是故意选的：
`kb_lint.py` 会跳过它们，模板本身能通过 lint。

| 模板 | 用途 |
|------|------|
| [method.md](method.md) | MTD：方法原理与边界 |
| [decision.md](decision.md) | DEC：决策及前提 |
| [experiment.md](experiment.md) | EXP：对比实验 |
| [pitfall.md](pitfall.md) | PIT：坑与排查信号 |
| [recipe.md](recipe.md) | RCP：端到端 checklist |
| [example.md](example.md) | 样例（放 examples/） |
