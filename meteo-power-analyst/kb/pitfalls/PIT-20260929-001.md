# REE/ESIOS 域名级 WAF 封锁：api.esios.ree.es 全站 403（token 有效也进不去）

> **类型**: pitfall
> **成熟度**: verified
> **创建时间**: 2026-09-29
> **最后引用**: 2026-09-29
> **标签**: esios, ree, spain, imperva, incapsula, waf, anti-scraping, 403, geoblock, china-ip-block, api, token, proxy
> **适用阶段**: architect, implement

## 背景

ESIOS/REE 的官方 API 是西班牙"缺口→电价"链路（PS-030/031/032/035）中唯一能给出**分技术实际出力 + 实时需求**的官方源。2026-09-29 用户成功申请到个人 token（REE 邮件原件确认：token 仅限本人使用、公开项目须落地自有服务器、禁止冗余/重复请求），遂实测其可用性。

## 内容

### 现象：403，但不是鉴权失败

| 请求 | 认证 | 结果 |
|---|---|---|
| `https://api.esios.ree.es/`（根路径） | 无 | **HTTP 403**，`text/html` 866 B |
| `https://api.esios.ree.es/indicators/600` | `Token token="…"` | **HTTP 403**，`text/html` 867 B |
| `https://api.esios.ree.es/indicators/600` | 不加引号 `Token token=…` | **HTTP 403**，同上 |
| `https://www.esios.ree.es/es` | — | **HTTP 403**，同上 |
| `https://www.ree.es/es` | — | **HTTP 403**，同上 |
| `https://apidatos.ree.es/es` | — | **HTTP 403**，同上 |

**判定依据（三条独立证据，结论一致）**：

1. **带/不带 token 返回同一张拦截页**；连**根路径**都 403 ⇒ 拦截发生在鉴权**之前**，不可能是 token 问题。
2. 响应体是 Imperva **Incapsula** 的标准拦截页：`X-Iinfo: 51-…` 响应头、`Set-Cookie: visid_incap_1885724=… Domain=.esios.ree.es`、`<script src="/_Incapsula_Resource?SWJIYLWA=…">`、`<iframe src="/_Incapsula_Resource?CWUDNSAI=…">`。
3. **有界面真实浏览器（Playwright + Chromium，非无头）同样 403** ⇒ 不是"JS 挑战 / 无头检测"，而是**域名级（网络出口 IP）封锁**。

对照测试（同机同网）：`www.omie.es`、`api.energy-charts.info`、`re.jrc.ec.europa.eu`、`api.open-meteo.com`、`transparency.entsoe.eu` 全部 **HTTP 200**；只有 `*.ree.es` 全族 403。⇒ 是本机所在网络（中国大陆出口）与 REE 域名之间的封锁，与项目其他数据源无关。

### 尝试过且无效的手段

| 手段 | 结果 |
|---|---|
| `curl_cffi` 模拟 Chrome/Safari/Edge 的 TLS/JA3 指纹（chrome / chrome124 / chrome120 / safari17_0 / edge101） | 全部 403 ⇒ **非指纹识别** |
| 浏览器式 User-Agent（Chrome 126） | 403 |
| 补 `Accept-Language: es-ES`、`Referer`、`Origin` | 403 |
| Playwright 无头 Chromium（可执行 JS 挑战） | 403 |
| Playwright **有界面** Chromium | 403 |
| 两种 Authorization 写法（带/不带引号） | 均 403（被拦截页覆盖，未到鉴权） |

### 可用替代路径

| 需求 | 替代 | 连通性（实测） | 备注 |
|---|---|---|---|
| 分技术实际出力 / 负荷 / 电价（西班牙，15 min，2015–） | **Energy-Charts (Fraunhofer ISE)** | ✅ 200 | **项目已在用（PS-030/031）**，免注册 |
| 日前电价（西班牙，小时/15 min） | **OMIE** 原始文件 | ✅ 200 | **项目已在用（PS-029）**，免注册 |
| 分技术实际出力 + 负荷 + 日前价（标准化、可回溯校验） | **ENTSO-E Transparency** | ✅ 门户 200；API 主机可达（`web-api.tp.entsoe.eu` 根 404 属正常，需路径+token） | 需**另申请**免费 token；PS-029 已列 |
| ESIOS 独有：5 min 高分辨率、PVPC、实时需求、**官方技术受限/弃电（restricciones técnicas）** | 仅 ESIOS | ❌ 本机不可达 | 需换网络或代理 |

### 处置办法

1. **换网络运行**：把 `skills/data-fetch-power/references/download_spain_esios.py` 与 `.env` 里的 token 带到**能访问 ree.es 的网络**（境外 VPS / 国际漫游 / 可访问的出口），跑完把 data/esios/ 拷回即可。
2. **挂代理**：在 `.env` 加一行 `ESIOS_PROXY=http://user:pass@host:port`（脚本与 `test_esios_api.py` 均自动读取，也认 `HTTPS_PROXY`）。
3. **先用替代源推进**：Energy-Charts 已覆盖项目 90% 的需求；ESIOS 的增量价值主要是**官方弃电/受限指标**与 5 min 分辨率。

### 避坑建议

1. **不要把 403 当 token 失效**：先看响应体是否是 Incapsula 拦截页（`_Incapsula_Resource` / `visid_incap`），再谈 token。
2. **不要浪费时间在指纹伪装**：TLS 指纹、UA、请求头全套都试过，均无效 ⇒ 是 IP/域名级，不是脚本层。
3. **下载脚本一律写成"代理可感知 + 按月可续传"**：既绕开封锁，也满足 REE 的 responsible-use 要求（不重复、不冗余请求）。
4. **token 只放 `.env`**（已在 `.gitignore`），且按 REE 邮件要求，任何公开项目须把数据落到自有服务器、不得让终端用户直连 REE。
