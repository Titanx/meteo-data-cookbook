# IEM ASOS 通道三坑：`missing=blank` 已废弃致 422、站清单端点改版返回 HTML、无效站静默失败

## 坑的描述（带数字）

2026-10-15/16 用 IEM（mesonet.agron.iastate.edu）批量拉德州 33 站 ASOS 时踩到三个坑：

1. **`missing=blank` 参数已废弃**：老写法 `...&missing=blank&...` 返回 **HTTP 422**
   （参数被拒），报错页面不说明是哪个参数。改成 `missing=M` 立即恢复。
2. **站清单端点改版**：`networks.php?network=TX_ASOS` 一类网络清单接口现在返回
   **HTML 页面**（不再是可以解析的 CSV/JSON），想程序化枚举"德州所有 ASOS 站"会拿到
   无法解析的响应；geojson 变体同样不可用。
3. **无效站静默失败**：`KEDT`（Eldorado）请求"成功"但没有逐时报文数据；`KLBK`
   是错误站号（拉伯克 Lubbock 是 **KLBB**）。两者都不会在 HTTP 层报错——
   只能靠行数/内容自检发现。

## 排查信号（下次怎么认出来）

- 422 且 URL 肉眼看没问题 ⇒ 逐个参数二分排查（本次二分定位到 `missing`）
- 请求"成功"但 `len(r.text) < 1000` 或解析后行数为 0 ⇒ 站号无效或该站无此数据类型
- 清单请求返回 `<html>` 开头 ⇒ 端点已改版，别硬解析
- 单站行数比同区域其他站少一个数量级 ⇒ 先查站号拼写（KLBK/KLBB 一字之差）

## 绕行方案

- **参数**：用 `missing=M` + `trace=T`（实测有效组合，见 `recipes/RCP-20261016-001` 第 1 节）
- **站清单**：放弃运行时枚举，**硬编码精选清单 + 每站一天探针请求验行数**后再批量拉
- **站号核验**：批量前对每个站发一个 `year1=2026&month1=1&day1=1` 的一天探针，
  行数 ≈24 的才入清单；下载后 `_manifest.csv` 记录每站状态/行数
- 站号权威源：ICAO 四字码以 aviationweather 官方检索为准，不确定先探针

## 真实案例

2026-10-15 德州 33 站下载：初版脚本用 `missing=blank` 全量 422；改为 `missing=M` 后恢复。
初版清单含 `KEDT`（无数据）与把拉伯克写成 `KLBK`；勘误为剔除 KEDT、改用 KLBB 后，
33/33 站全部成功（每站约 5.2 万行，缺失率 <0.5%）。
