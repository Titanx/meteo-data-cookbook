# EIA-930 储能列的口径静默切换：BAT 净额化、UES 停报成 NaN；年度聚合弹性会被 3% 样本搬动

> 最后更新: 2026-10-03
> 成熟度: **verified**（2026-10-03 储能归因分析实测；切换点前后日中位数连续性 + 月度最大放电交叉验证）
> 适用场景: 用 EIA-930 的 BAT/UES 列做 ERCOT 储能行为分析、容量估计或任何跨 2025-12 的储能统计

两个坑 + 一个分析陷阱，共同点仍是**不报错**：列还在、代码照跑，
但储能统计的语义已经变了，或者弹性"漂移"根本不是物理变化。

## 坑 1：2025-12-15 07:00 UTC 起 BAT/UES 静默换语义

EIA-930 的储能报告方式在 **2025-12-15 07:00 UTC** 切换：

| 列 | 切换前 | 切换后 |
|---|---|---|
| BAT | **毛放电**，恒 ≥ 0 | **净额**（放电−充电），可正可负 |
| UES | 充电负载，恒 ≤ 0 | **停报**（返回 NaN / 缺失） |

验证切换是"同一物理队列的重新报告"而非装机跳变：切换点前后**日中位数连续**
（切换前 BAT+UES ≈ −340~−1090 MW，切换后 BAT ≈ −330~−505 MW）。

### 排查信号

- BAT 列出现**负值** → 一定跨过了切换点（切换前物理上不可能）
- UES 列某时刻起**整段 NaN** → 同上
- 储能"充电"统计突然**归零** → 把切换后缺 UES 当成"没在充"
- 储能"放电"中位数**跳变** → 把净额当毛放电（负值小时被算进"低放电"）
- 任何 `bat + ues` / `df.sum()` 在切换后**整列变 NaN** → UES 的 NaN 传染

### 绕行：三条序列按切换点拼接

| 序列 | 切换前 | 切换后 | 用途 |
|---|---|---|---|
| net（净出力） | BAT + UES | BAT | 事件行为分析（**全期一致，优先用**） |
| dis（放电） | BAT（毛放电） | max(BAT, 0) | 容量代理 |
| chg（充电） | −UES（毛充电） | max(−BAT, 0) | 机制核对 |

实现要点（`battery_elasticity_attribution.py` 的 `build_storage`）：

```python
SWITCH = pd.Timestamp("2025-12-15 07:00", tz="UTC")
if "UES" in piv.columns:
    ues = piv["UES"].copy()
    ues[ues.index >= SWITCH] = 0.0   # 停报段显式置 0，防 NaN 传染
else:
    ues = pd.Series(0.0, index=piv.index)
pre = piv.index < SWITCH
net = bat + ues
dis = bat.where(pre, bat.clip(lower=0))
chg = (-ues).where(pre, (-bat).clip(lower=0))
```

**附带口径风险**：净额化后"同一小时既充又放"的调频行为被洗掉 ⇒
切换后的 dis 中位数**系统性低估**。但 net 序列不受影响（净充电为负不可能是洗出来的），
跨切换点的行为结论**尽量落在 net 上**。

## 坑 2：没有逐周装机序列，容量只能做代理

ERCOT 储能无公开的逐周/逐月装机序列，可用**滚动 90 天放电 P99** 作为可调度容量代理：
样本期（2025-01 ~ 2026-09）从 **3.1 GW 增至 9.9 GW**，
与月度最大放电口径（3.6 → 11.9 GW）走势一致。

局限必须记住：该代理受**电价行为影响**（利用率上限），
只可用于交互项，**不可当精确容量度量**；且与时间趋势共线，
交互项只能做关联解释、不能做因果归因。

## 坑 3：年度聚合弹性对样本构成极度敏感（"漂移"可能是假象）

2026 年头条弹性：9 月初口径（数据止于 9 月初）**+5.43 %/GW** →
全样本 Jan–Sep **+5.30**——**最后三周（约 3% 样本）就能移动头条 ±0.4**。
年度聚合弹性不是稳定结构参数。

此前知识库记录的"+5.08 → +5.43 上升"（2025 全年 vs 2026 Jan–Sep），
经**同季匹配池化**检验（季度 FE + 季度×缺口交互 + 年份指示，Q1–Q3 池化）后：
漂移 **−0.29 %/GW（SE 0.31，不显著）**——上升是构成效应
（2026 相对 2025 缺 Q4、偏重高弹性的 Q1–Q2）。

实现要点：季节匹配池化模型**必须包含年份指示变量 `i_y26`**
（初始实现漏掉会得到有偏的漂移估计）；
所有季节匹配口径的漂移点估计均为小幅负值且不显著时，
不要按未匹配的年度头条下"跨年变化"结论。

弹性的年内形状是**冬高夏低**（Q1 高、Q3 低，波动 ±2 %/GW）且两年重复，
与容量单调增长**不同步**——季节数值主导弹性水平，容量不是一阶变量。

## 排查信号（汇总）

- BAT 列有负值 / UES 列整段 NaN / 储能统计在 2025-12-15 附近跳变 → **坑 1**
- 跨切换点的 sum/mean 出现 NaN → 坑 1 的 NaN 传染
- "储能放电中位数"跨年大幅下降但 net 没动 → 坑 1 的净额化偏读，改看 net
- 需要容量但只有出力序列 → **坑 2**，用 90 天放电 P99，明示局限
- 两个时段的弹性差 < 样本尾部重算的移动量（如 ±0.4）→ **坑 3**，先做季节匹配再谈漂移
- 跨年比较的两个样本**季节构成不同**（一个缺 Q4、一个偏重 Q1） → 坑 3 的标准现场

## 绕行方案

1. 跨 2025-12-15 的储能分析：按上面三行拼接表统一序列，`UES` 停报段显式置 0
2. 行为结论优先落在 **net**；dis/chg 只做辅助，且切换后注明"净额化低估放电"
3. 容量用滚动 90 天放电 P99 做代理，只进交互项
4. 跨年弹性比较一律先做**同季匹配**（池化 + 年份指示 + 季节 FE），
   头条数字必须注明样本窗口
5. 检验"某变化是否构成效应"的低成本办法：把两段样本截齐到同季再重估

## 真实案例

2026-10-03 储能归因研究（PS-045，数据刷到 2026-09-30）：
用同一 EIA 面板构建 2025-01~2026-09 全样本（14,954 小时，白天 8,190 小时），
先踩坑 1（2026 年 UES 缺失导致 bat_net 全 NaN），修拼接后完成
弹性路径 → 漂移分解 → 事件机制三层分析，
最终推翻"弹性上升 = 储能放大传导"的悬置假设（漂移是构成假象），
并发现储能行为已切换为"日前资产"（详见 CONCLUSIONS §2.19）。
