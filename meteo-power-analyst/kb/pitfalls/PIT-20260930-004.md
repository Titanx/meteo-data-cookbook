# NASA POWER hourly/daily 默认是 LST（当地太阳时）：漏传参数会整段错位，且不能用时区偏移去换算

> 最后更新: 2026-09-30
> 成熟度: **verified**（官方文档 + 多点位实测复现）
> 适用场景: 任何 NASA POWER hourly / daily 取数，尤其是跨国、跨经度或需要与 UTC 序列对齐的场景

## 1. 坑的描述

`time-standard` **不传时默认 `LST`**，而且 **hourly 与 daily 都默认 LST**（月度/气候态才是 UTC）。
官方定义：**LST = Local Solar Time（当地太阳时）**——15° 带宽，带宽中央经线处**太阳正午对应 12:00**。

两类误用都会整段错位：

- 把 LST 当成 **UTC**：整条序列的时点标签平移若干小时（按经度而定，最多 ±12 h）
- 把 LST 当成"**当地标准时 / 含夏令时的民用时区**"：试图用 `America/Chicago`、`CET+1` 这类时区偏移去换算 LST
  ⇒ 必然错。**LST 是太阳时，与民用时区无关**；实测马德里在同一物理时刻的 LST 与 UTC 标签只差约 0.25 h，
  而西班牙民用时区是 UTC+1，用民用时区换算会引入 1 h 的假偏移。

**标签差 ≈ round(经度 / 15) 小时**（实测与解析值一致）。

## 2. 实测证据（整条日曲线互相关，2026-09-30）

| 点位 | 经度 | LST 标签 − UTC 标签 | 说明 |
|---|---|---|---|
| ERCOT 西德州 | −102.5 | **+7 h**（LST 峰值 12 时 / UTC 峰值 19 时） | 漏传参数时逐时相关 **0.98 → 0.31** |
| 西班牙 A Coruña | −8.5 | +1 h | |
| 西班牙 加那利 | −15.5 | +1 h | |
| 西班牙 Sevilla / Madrid / Barcelona | −6.0 / −3.7 / +2.2 | **0 h** | 大陆靠近本初子午线，两套标签重合 |
| 河西走廊 | +100.0 | **−6 h** | |

LST 锚定太阳正午的判别法：缺省下**辐照峰值与最低太阳天顶角（SZA min）同时落在 12 时**，
且与经度无关（马德里、河西、西德州均如此）→ 说明锚点是太阳正午，不是任何民用时区。

## 3. 本项目现状（已核）

- `skills/data-fetch-nwp/references/download_nasa_power_ercot_pv.py` **显式传 `time-standard=UTC`**（正确）
- `skills/data-fetch-power/references/download_spain_data.py` 与 `download_spain_data_multi.py`
  **都没传** ⇒ 2023–2025 西班牙 npz 是 **LST 标签**；下游 `skills/pv-power-model/references/model_spain_pv_power.py`
  用 tz-naive 解析后交给 pvlib（按 UTC 解释）
- **实际影响≈0**：120 个 hub 中 118 个位于 LST 与 UTC 标签重合的经度带，只有 2 个加那利 hub（容量占 0.5%）真错 1 h
  ⇒ 这解释了为什么西班牙链路在 lag0 就取到 r≈0.98（若是 ERCOT 那种 7 h 错位，相关会塌掉）

## 4. 排查信号

- 辐照峰值不在 12 时附近（LST 下应恒在 12 时附近）
- 辐照峰值与最低 SZA **不同时**出现 → 时点已错位
- 相关系数在 lag±1 反而高于 lag0
- 报告里出现"当地标准时""MST/CET 偏移"等与 LST 并列的表述 → 语义已混

## 5. 绕行方案

1. **一律显式传 `time-standard=UTC`**，不依赖默认值；把响应头的 `time_standard` 字段
   （JSON 路径 `header.time_standard`，取值 `UTC`/`LST`）随数据一起落盘
2. 不要用民用时区/夏令时规则换算 LST；真要用 LST，只能按经度或响应头声明处理
3. 复核既有结论时，先确认原数据的标签标准，再看 lag 曲线是否与其一致

## 6. 附带纠正（原条目表述有误）

`recipes/RCP-20260928-007` 局限 #4 原写"西班牙 NASA POWER 时间轴存在约 **1h 偏移**"，
与该处自己给出的数字（lag0 r=0.971 已是最高值）矛盾。实测 2023/2024/2025 的西班牙面板
**lag0 相关均为最高**（0.982 / 0.977 / 0.968）⇒ **不存在整点偏移**。该条已改写。
