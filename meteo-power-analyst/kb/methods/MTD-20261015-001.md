# 机场 ASOS/METAR 观测获取：IEM ASOS 与 aviationweather 使用

> 类型: guideline
> 成熟度: verified（2026-10-15/16 实跑批量：33 站 × 6 年全部成功，见 `recipes/RCP-20261016-001`）
> 标签: asos, awos, metar, iem, aviationweather, texas, ercot, observation
> 适用阶段: implement, verify

## 背景
ERCOT/德州主线需要机场自动观测（ASOS/AWOS → METAR）作观测真值。相比 Meteostat 聚合层（会被"预报混进观测"污染，见 PIT-20260930-007），IEM 与 aviationweather 提供**原始报文/METAR**，可作为验证真值。

## 推荐做法（recommend）

### 1. IEM ASOS 历史逐时（主力）
GET：
```
https://mesonet.agron.iastate.edu/cgi-bin/request/asos.py
  ?station=KDFW            // 可逗号分隔多站，或空=全站
  &data=all
  &year1=2025&month1=1&day1=1&hour1=0&minute1=0
  &year2=2025&month2=1&day2=2&hour2=23&minute2=59
  &tz=Etc/UTC
  &format=onlycomma         // onlycomma=CSV；还可 latlon=yes/elev=yes
  &missing=M                // 仅允许 M|null|empty
  &trace=T
  &direct=no
  &report_type=3            // 1=含特殊观测(更密) 3=逐时例行 4=仅例行；"all" 组合
```
返回 CSV 表头（实测 30 列）：
`station,valid,tmpf,dwpf,relh,drct,sknt,p01i,alti,mslp,vsby,gust,skyc1..4,skyl1..4,wxcodes,ice_accretion_1hr,ice_accretion_3hr,ice_accretion_6hr,peak_wind_gust,peak_wind_drct,peak_wind_time,feel,metar,snowdepth`

要点：
- **时间**：`valid` 为 UTC（`tz=Etc/UTC`）；站上自动站数据含分钟，`report_type=3` 逐时。
- **`metar` 列即原始报文**，可直接核对量纲，规避 Meteostat 单位切换坑。
- **单位**：`tmpf`/`dwpf` 华氏，`sknt` 节，`alti` 英寸汞柱，`mslp` hPa，`p01i` 1小时降水英寸。**用前务必换算**（对比 Meteostat 的 m/s/°C）。
- 大规模多站下载：官方建议限制并发、分批；大请求返回 gzip。

### 2. aviationweather.gov METAR 原始（实时近实时，免 key）
```
https://aviationweather.gov/api/data/metar?ids=KDFW&format=raw&hours=2
```
返回 `METAR KDFW ...` 原始报文，适合近实时观测；`ids` 可多站，`hours` 回溯小时。

### 3. AWOS/ASOS 站点清单
- FAA 官方 ASOS/AWOS 站点列表 / aviationweather stations；按 ICAO 筛德州。
- IEM `asos.stations` 提供站元数据（坐标/海拔）。

## 禁止做法（avoid）
- ❌ 把 `tmpf`/`sknt`/`alti` 当 °C/m/s/hPa 直接用（英制单位）
- ❌ 用 Meteostat 默认 `Hourly()` 当观测（尾部是 DWD MOSMIX 预报，见 PIT-20260930-007）
- ❌ 用 AWOS 精简站代替完整 ASOS 做要素全集分析

## 适用场景
ERCOT/德州地面观测锚点、模式 vs 观测验证、短期温度/风/降水联动。
