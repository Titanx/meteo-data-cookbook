# Open-Meteo API 使用指南（含 HRRR/GFS 等 NWP 预报）

> **类型**: guideline
> **成熟度**: verified
> **创建时间**: 2026-07-18
> **最后引用**: 2026-09-16
> **标签**: openmeteo, api, era5, forecast, hrrr, gfs, nam, nbm, nwp, free, no-api-key, ercot, wind, solar, cape
> **适用阶段**: implement, verify

## 背景

Open-Meteo 是开源天气 API，提供免费、无 key、非商业用途开放的访问方式，集成 ERA5/IFS/GFS/HRRR/NAM 等多家国家气象中心的模式输出。2026-08-12 实测验证 **HRRR 3km CONUS 完全可用**，是 ERCOT 区域风电/光伏/雷暴分析的最优 NWP 数据源。

## 内容

### 1. API 端点总览

| 端点 | 用途 | 数据源 | 时间范围 |
|------|------|--------|---------|
| `https://api.open-meteo.com/v1/forecast` | 实时预报 | GFS/HRRR/ICON/ECMWF 等 | 未来 7-16 天 |
| `https://historical-forecast-api.open-meteo.com/v1/forecast` | 历史预报归档 | 同实时预报 | 见 §2.1（**各模式起点不同**，最早 2016-01） |
| `https://archive-api.open-meteo.com/v1/archive` | 历史再分析 | ERA5/ERA5-Land/IFS | 1940 至今 |
| `https://seasonal-api.open-meteo.com/v1/seasonal` | S2S 季节尺度预报 | ECMWF EC46(46天)+SEAS5(7个月), 51成员（接口每个变量暴露 50 个 `_memberNN` + 集合均值） | 未来 46 天~7 个月（可回导历史） |
| `https://ensemble-api.open-meteo.com/v1/ensemble` | 集合预报 | GFS/ECMWF/ICON/GEM 等集合 | 见 §11（**必须显式写 `models=`**） |

**核心特点**：
- 无需 API key（非商业用途，每日 < 10,000 次调用）
- 支持 JSON / CSV / XLSX 三种输出格式
- **自动选择最优模式**（Best Match），也可通过 `models=` 手动指定
- 支持时区转换，避免 UTC 转换错误
- **支持多坐标批量请求**（逗号分隔，单次最多 6+ 站点）

### 2. 支持的 NWP 预报模型（ERCOT 重点）

| 模型 | 参数名 | 区域 | 分辨率 | 预报长度 | 更新频率 | 实时可用自 |
|------|--------|------|--------|---------|---------|-------|
| **HRRR** | `ncep_hrrr_conus` | CONUS | **3 km** | 18h (48h @0/6/12/18Z) | 每小时 | **2018-01** |
| **HRRR 15min** | `ncep_hrrr_conus_15min` | CONUS | 3 km | 18h | 每小时 | 同上 |
| **GFS** | `ncep_gfs_seamless` | 全球 | 0.11° (~13 km) | 16天 | 每6小时 | 2021-03 |
| **NAM** | `ncep_nam_conus` | CONUS | 3 km | 60h | 每6小时 | 2025-09 |
| **NBM** | `ncep_nbm_conus` | CONUS | 2.5 km | 11天 | 每小时 | 2024-10 |
| AIGFS (AI) | `ncep_aigfs025` | 全球 | 0.25° | 16天 | 每6小时 | 2026-01 |
| HGEFS (集合) | `ncep_hgefs025_ensemble_mean` | 全球 | 0.25° | 10天 | 每6小时 | 2026-01 |

> **参数名更正**（2026-09-30 实测）：AI 模式是 `ncep_aigfs025`、集合均值是 `ncep_hgefs025_ensemble_mean`。
> 原先写成带下划线的 `ncep_aigfs_0_25` / `ncep_hgefs_0_25_ensemble_mean`，API 直接拒绝：
> `Invalid value: Cannot initialize MultiDomains from invalid String value ncep_aig...`。**参数名里没有 `_0_25` 这种写法**。

#### 2.1 历史预报归档起点（**逐模式不同**，勿用一个年份概括）

2026-09-30 实测（`historical-forecast-api`，固定点位 32.8°N/96.8°W，逐月 15 日探 `temperature_2m` 是否非空）：

| 模型 | 归档首个有值的月 |
|---|---|
| `jma_seamless` | **2016-01** |
| `ncep_hrrr_conus` / `ncep_gfs_seamless` / `gfs_seamless` | **2018-01** |
| `ukmo_seamless` | 2022-03 |
| `icon_seamless` | 2022-12 |
| `meteofrance_seamless` | 2024-01 |
| `ecmwf_ifs025` | 2024-02 |
| `ncep_nbm_conus` | 2024-10 |
| `ncep_nam_conus` | 2025-09 |

**两个口径要分清**：

- **API 允许的 `start_date` 下限统一是 2016-01-01**（越界会返回 HTTP 400，报文回显
  `Parameter 'start_date' is out of allowed range from 2016-01-01 to <今天+15天>`）——
  这是**接口级**约束，与模式无关，**不能拿它当"数据起点"**。
- **各模式在该区间内实际有数据的起点差异很大**（上表，从 2016-01 到 2025-09，跨 10 年）。
  在起点之前请求不会报错，只是**整列返回 `null`**（静默空值，必须自己判空）。

### 3. ERCOT 风电关键变量（HRRR 实测可用）

**2026-08-12 实测验证**，达拉斯 KFWS 80m 风：

| 变量 | 参数名 | 可用性 | 说明 |
|------|--------|--------|------|
| **80m 风速** | `wind_speed_80m` | ✅ | 风电核心，实测均值 31 m/s |
| 80m 风向 | `wind_direction_80m` | ✅ | 实测 167-204° 南风 |
| 10m 风速 | `wind_speed_10m` | ✅ | 地表风 |
| 10m 阵风 | `wind_gusts_10m` | ✅ | 雷暴阵风 |
| 100m 风速 | `wind_speed_100m` | ⚠️ HRRR 无此层 | 可用 GFS 替代 |
| 120m 风速 | `wind_speed_120m` | ⚠️ HRRR 无此层 | 可用 GFS 替代 |

**注意**：HRRR 直接提供 80m 风场，**不提供 100m/120m 风场**。GFS 提供 80m/100m/120m/180m/200m 多层风。

```python
import requests
import urllib.parse

# HRRR 实时风电查询
params = {
    "latitude": 32.895,  # KFWS Dallas
    "longitude": -97.037,
    "models": "ncep_hrrr_conus",
    "hourly": [
        "temperature_2m",
        "wind_speed_80m",
        "wind_direction_80m",
        "wind_speed_10m",
        "wind_gusts_10m",
        "surface_pressure",
    ],
    "forecast_days": 2,
    "timezone": "America/Chicago",
}
url = "https://api.open-meteo.com/v1/forecast?" + urllib.parse.urlencode(params, doseq=True)
r = requests.get(url, timeout=30)
data = r.json()
```

### 4. ERCOT 光伏关键变量（HRRR 实测可用）

| 变量 | 参数名 | 说明 |
|------|--------|------|
| 短波辐射 GHI | `shortwave_radiation` | 水平面总辐射，**光伏预测核心** |
| 直接辐射 | `direct_radiation` | 直接辐射分量 |
| 漫射辐射 DHI | `diffuse_radiation` | 漫射辐射分量 |
| 法向直接辐射 DNI | `direct_normal_irradiance` | 聚光光伏 |
| 云量 | `cloud_cover` | 总云量 |

**实测（2026-08-12）**：Houston GHI 均值 630 W/m²，峰值 979 W/m²，云量 20%

```python
params = {
    "latitude": 29.760,  # KHGX Houston
    "longitude": -95.369,
    "models": "ncep_hrrr_conus",
    "hourly": [
        "shortwave_radiation",
        "direct_radiation",
        "diffuse_radiation",
        "direct_normal_irradiance",
        "cloud_cover",
        "temperature_2m",
    ],
    "forecast_days": 2,
}
```

### 5. 对流参数（雷暴关联）

| 变量 | 参数名 | 说明 |
|------|--------|------|
| CAPE | `cape` | 对流有效位能，**雷暴分析核心** |
| 抬升指数 | `lifted_index` | 负值越小越不稳定 |
| 对流抑制 | `convective_inhibition` | 触发雷暴所需能量 |
| 雷暴概率 | `thunderstorm_probability` | 概率预报 |
| 降水概率 | `precipitation_probability` | 概率预报 |
| 边界层高度 | `boundary_layer_height` | PBL 高度 |
| 冻结层高度 | `freezing_level_height` | 冰雹/冻雨判断 |

**实测（2026-08-12 达拉斯）**：CAPE 最大 2620 J/kg，Lifted Index -5.9，PBL 最高 2460m

### 6. 15 分钟分辨率

HRRR 提供 `ncep_hrrr_conus_15min` 模式，15 分钟间隔的精细数据：

```python
params = {
    "latitude": 32.895,
    "longitude": -97.037,
    "models": "ncep_hrrr_conus_15min",
    "minutely_15": [
        "temperature_2m",
        "wind_speed_80m",
        "shortwave_radiation",
        "precipitation",
        "cape",
    ],
    "forecast_minutely_15": 48,  # 12 小时
}
```

### 7. 历史预报数据

**Historical Forecast API** 提供与实时预报相同的模型数据，归档自 2018-01：

```python
url = "https://historical-forecast-api.open-meteo.com/v1/forecast"
params = {
    "latitude": 32.895,
    "longitude": -97.037,
    "models": "ncep_hrrr_conus",
    "start_date": "2024-07-15",
    "end_date": "2024-07-17",
    "hourly": ["temperature_2m", "wind_speed_80m", "cape", "shortwave_radiation"],
}
```

**实测（2024-07-15 达拉斯）**：80m 风均值 20.2 m/s，峰值 32.7 m/s；GHI 峰值 996 W/m²；CAPE 最大 3280 J/kg。

### 8. 多站点批量请求

逗号分隔坐标，单次请求最多 6+ 站点，返回数组：

```python
lats = "32.895,29.760,31.997"  # Dallas, Houston, Midland
lons = "-97.037,-95.369,-102.078"
params = {
    "latitude": lats,
    "longitude": lons,
    "models": "ncep_hrrr_conus",
    "hourly": ["wind_speed_80m", "shortwave_radiation", "temperature_2m"],
    "forecast_hours": 6,
}
# 返回 data[0] = Dallas, data[1] = Houston, data[2] = Midland
```

### 9. 气压层变量

HRRR/GFS 支持气压层数据（1000-100 hPa），但目前 Open-Meteo 对 HRRR 气压层支持有限（仅 temperature_2m 等表面层可用）。GFS 气压层更完整，参数名：

```
pressure_levels=temperature,wind_speed,geopotential_height&
pressure_levels_levels=850,700,500,300,200
```

### 10. 多模型对比（HRRR vs GFS vs NAM vs NBM）

| 维度 | HRRR 3km | GFS 0.11° | NAM 3km | NBM 2.5km |
|------|----------|-----------|---------|-----------|
| 80m 风（实测） | 26.8 m/s | 26.8 m/s | 23.2 m/s | 24.7 m/s |
| 预报长度 | 48h | 16天 | 60h | 11天 |
| 更新频率 | 每小时 | 每6小时 | 每6小时 | 每小时 |
| 区域 | CONUS | 全球 | CONUS | CONUS |
| 特色 | 高时空分辨率 | 全球覆盖 | 63层垂直 | 统计后处理 |

### 11. 可用新端点（2026 年新增）

Open-Meteo 2026 年扩展了多个专用 API：

| 端点 | 用途 |
|------|------|
| `https://ensemble-api.open-meteo.com/v1/ensemble` | **集合预报**（子域是 `ensemble-api`，主域 404） |
| `https://marine-api.open-meteo.com/v1/marine` | 海洋预报 |
| `https://air-quality-api.open-meteo.com/v1/air-quality` | 空气质量 |
| `https://seasonal-api.open-meteo.com/v1/seasonal` | S2S 季节尺度（EC46+SEAS5）预报 |
| `https://api.open-meteo.com/v1/climate` | 气候变化 |

> ⚠️ **专用 API 一律在独立子域**，主域 `api.open-meteo.com/v1/<名字>` 一律 404。实测（2026-09-30）：
> `api.open-meteo.com/v1/seasonal` → 404、`api.open-meteo.com/v1/ensemble` → 404。季节预报的正确端点见 PS-017。

**集合预报的三个要点**（2026-09-30 实测）：

1. **子域**：`https://ensemble-api.open-meteo.com/v1/ensemble`
2. **必须显式写 `models=`**：不写时默认 `best_match`，而集合 API 不支持它，直接 400 ——
   ```
   HTTP 400  Model 'best_match' is not supported by the Ensemble API.
             Please select a specific ensemble model.
   ```
3. **不存在 `ensemble-mean` 端点**：`ensemble-api.open-meteo.com/v1/ensemble-mean` 实测 **404**
   （`api.open-meteo.com/v1/ensemble-mean` 同样 404）。集合均值是响应里的**基础字段**
   （`temperature_2m` 本身即集合均值），不需要单独端点。

**各集合模式的成员数不同**（同一变量名的 `_memberNN` 字段数）：

| 集合模式 | 成员数 | 区域 |
|---|---|---|
| `gfs_seamless` / `gfs025` / `gfs05` | **30** | 全球 |
| `ecmwf_ifs025` | **50** | 全球 |
| `icon_seamless` | **39** | 全球 |
| `gem_global` | **20** | 全球 |
| `bom_access_global` | 0（无可用成员） | 全球 |

### 13. 不得购买通配符

- ❌ 商业用途未购买商业授权
- ❌ 每日调用超过 10,000 次
- ❌ 未设置 `timeout` 导致请求挂起
- ❌ 未指定 `timezone` 导致时间偏移
- ❌ 长时间序列（>1 年）单次请求，应分批拉取
- ❌ 未保存原始 JSON，仅存转换后的 CSV（丢失元数据）

## 适用场景

- ERCOT 区域风电/光伏功率预测（HRRR 3km 80m 风场 + GHI）
- 德州强对流天气监测（CAPE/Lifted Index/雷暴概率）
- 历史事件回测（Historical Forecast API 2018 年起）
- 科研项目的气象数据获取（无需申请 API key）
- 替代付费 API 的低成本方案

## 不适用场景

- 商业产品（需购买商业授权）
- 大规模业务系统（每日 > 10,000 次调用）
- 实时性要求 < 1 分钟的场景
- 需要原始 GRIB2 模式输出（应直接访问 NOMADS）
- 100m/120m 风场需要 HRRR 数据（HRRR 仅提供 80m，GFS 提供多层）
