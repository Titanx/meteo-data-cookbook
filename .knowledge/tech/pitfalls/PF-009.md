## 背景

美国站和中国站探空数据垂直分辨率差异巨大（约 51 倍），直接比较原始数据会导致误导性结论。美国站含 1 秒级高分辨率中间层数据（~4000-8000 行/次），而中国站仅提供规定层和特性层数据（~100-200 行/次）。

|------|------|------------|-------------------|
| 德州 | 72249 Fort Worth | 4216 | 27x |

## 陷阱 1: 直接比较热力指数

### 表现
美国站的高分辨率数据包含更多大气层细节，但热力指数（DCAPE、CAPE 等）的提取结果是标量值，不受垂直分辨率影响，可以直接比较。

### 结论
热力指数可直接比较，无需调整。

## 陷阱 2: 直接比较垂直廓线

### 表现
如果将美国站 4000 行数据直接与中国站 140 行数据绘制在同一张图上，美国站曲线会显得更"平滑"，但这只是采样密度差异，不代表真实物理差异。

### 解决方案
插值到标准气压层后再比较：

```python
STANDARD_LEVELS = [1000, 925, 850, 700, 500, 400, 300, 250, 200, 150, 100, 70, 50, 30, 20, 10]

# 按气压降序排列
sort_idx = np.argsort(-pres)
pres = pres[sort_idx]
temp = temp[sort_idx]

# 线性插值到标准层
for level in STANDARD_LEVELS:
    if level <= pres.max() and level >= pres.min():
        T_level = np.interp(level, pres[::-1], temp[::-1])
```

## 陷阱 3: 忽略上层截断

### 表现
日本站数据从 ~200 hPa 开始截断（仅 30-70 行），无法获得平流层信息。中国站数据从 100 hPa 左右开始有零星数据，但标准层只到 100 hPa。

### 解决方案
- 比较只限于共同覆盖的气压层（如 1000-200 hPa）
- 日本站排除在高层比较之外

## 陷阱 4: 72251 Dallas-FW 12Z 系统性缺失

### 表现
72251 (Dallas-FW) 在 12Z 时次系统性无数据，仅 00Z 有探空记录。这不是下载失败，而是该站仅 00Z 进行探空观测。

### 解决方案
- 下载脚本自动跳过缺失时次，记录为"no data"而非"error"
- 分析时注意该站的样本量约为其他站的一半（32 vs 58-59）

## 标准化比较建议

1. **热力指数**：直接比较（标量值，不受分辨率影响）
2. **垂直廓线**：先插值到标准气压层，再计算区域平均
3. **统计指标**：按站点分别统计，再按区域聚合
4. **时间序列**：保留原始分辨率，注意采样频率差异
