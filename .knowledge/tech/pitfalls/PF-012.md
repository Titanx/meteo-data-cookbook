# [PF-012] CMA 气象数据访问陷阱：CMADaaS 需内网、data.cma.cn API 受限、nmc-met-io 不支持 LMI

> **类型**: pitfall
> **成熟度**: verified
> **创建时间**: 2026-09-07
> **最后引用**: 2026-09-07
> **标签**: cma, cmadaas, data.cma.cn, nmc-met-io, fy4, lmi, vpn, intranet, china, api, authentication, python
> **适用阶段**: architect, implement

## 背景

中国气象局（CMA）数据平台有三层访问途径：CMADaaS 内部 API、data.cma.cn 公开 API、nmc-met-io Python 库。2026-09-07 实测发现三者在实际使用中均存在限制：CMADaaS 需内网 VPN、data.cma.cn API 账号需单独注册且参数格式严格、nmc-met-io 库不支持 FY-4 LMI 闪电数据。

## 内容

### 陷阱一：CMADaaS 需 CMA 内网/VPN

| 项目 | 说明 |
|------|------|
| CMADaaS API | `http://10.20.76.55:8088` (内网 IP) |
| DNS 解析 | 公网无法解析 |
| 访问方式 | 需 CMA 内网或 VPN |
| VPN 获取 | 仅限 CMA 内部人员/合作单位，不对外 |

**影响**：外部研究者无法通过 CMADaaS 获取实时气象数据，包括 FY-4 全部产品、地面观测、雷达拼图等。

### 陷阱二：data.cma.cn API 账号注册独立

| 项目 | 说明 |
|------|------|
| 网址 | https://data.cma.cn |
| 认证 | 需注册账号 + 手机验证 |
| API 接口 | `https://api.data.cma.cn` |
| 陷阱 | data.cma.cn 网站账号 ≠ CIMISS/CMADaaS API 账号 |

**实测发现**：
- 网站注册账号 `xhlcn@163.com` 可登录网站，但 API 返回 `-1002 用户不存在`
- CIMISS API 系统（旧版）与 data.cma.cn 网站使用不同账号体系
- API 需单独申请，审批流程不透明
- 密码含特殊字符（如 `*`）会触发 SQL 注入防护拒绝

### 陷阱三：nmc-met-io 库功能限制

| 功能 | 状态 | 说明 |
|------|------|------|
| cmadaas_* 函数 | 不可用 | 需内网 CMADaaS |
| cache_cache_* 函数 | 部分可用 | 但需 CMADaaS 后端 |
| FY-4 LMI 数据 | **不支持** | 无 LMI 相关接口 |
| FY-4 AGRI 数据 | 支持 | 但需 CMADaaS 内网 |
| 地面观测 | 支持 | 但需 CMADaaS 内网 |

**实测发现**：
- `nmc-met-io` 库文档中列出 `cmadaas_analysis_by_time` 等函数，但安装版本中实际不可导入
- 该库依赖 CMADaaS 后端，公网环境下全部超时
- FY-4 LMI 闪电数据无任何接口支持

### 替代方案

| 数据需求 | 替代数据源 | 认证 | 延迟 | 推荐度 |
|----------|-----------|------|------|--------|
| 中国闪电 | NSMC 官方门户 | 注册 | 分钟级 | ⭐⭐⭐ |
| 中国闪电(历史) | 中科院订正数据集 2019-2023 | 公开 | 归档 | ⭐⭐⭐ |
| 中国地面观测 | Meteostat | 无需 | 1-3天 | ⭐⭐ |
| 中国 NWP 预报 | Open-Meteo (GFS/ICON) | 无需 | 实时 | ⭐⭐⭐ |
| 中国探空 | 怀俄明大学 WSGI | 无需 | 实时 | ⭐⭐⭐ |
| 中国降水 | GPM IMERG | Earthdata | 14h | ⭐⭐⭐ |
| 全球再分析 | Open-Meteo ERA5 | 无需 | 5天 | ⭐⭐⭐ |

### 避坑建议

1. **优先使用公开国际数据源**：NASA Earthdata、NOAA AWS S3、Open-Meteo 等从中国可正常访问
2. **CMA 数据仅作为补充**：当国际数据源无法覆盖时考虑 NSMC 官方门户手动下载
3. **不依赖 nmc-met-io 库**：该库核心功能依赖内网，公开版功能有限
4. **密码避免特殊字符**：data.cma.cn API 对 `*` 等字符触发 SQL 注入防护，建议纯字母数字
5. **不花时间申请 CMA VPN**：除非有正式合作关系，否则审批极难通过
