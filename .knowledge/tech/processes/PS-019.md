## 背景

NSRDB (National Solar Radiation Database) v3.2.2 GOES 版提供 1998 年至今 5 分钟分辨率、2 km 网格的 GHI/DNI/DHI 三分量辐照度（GOES 卫星反演 + 云光学模型），是北美光伏建模的标准基准（可直接接 pvlib PVWatts 出力链路，PS-006）。相比 NASA POWER（MERRA-2 再分析 1 h/0.5°，GL-006）与 SURFRAD（7 站点实测，PS-005），NSRDB 兼具高分辨率与全境覆盖。难点：**单年文件 1.5~2.4 TB**，必须部分读取（lazy read），不能整文件下载。

## 内容

### 1. 数据源与结构

- **访问**: `nrel-pds-nsrdb.s3.amazonaws.com`（AWS S3 匿名，registry.opendata.aws/nrel-pds-nsrdb）
- **样例**: `GOES/conus/v3.2.2/nsrdb_conus_irradiance_2022.h5`（~1.8 TB；另有 1998 起各年）
- **根节点**: `ghi / dni / dhi / fill_flag / time_index / meta`，version 4.0.0
- **数据集结构**:
  - `/ghi` uint16 `[105120, 2842719]` = 5 分钟时隙 × 像素（105120 = 365×288），值即 W/m²（scale_factor=1，经日循环量级验证）
  - `/time_index` **变长字符串数组**（非数值 epoch），形如 `2022-01-01 00:00:00+00:00`，UTC 起步
  - `/meta` compound（122 B/条 × 2842719 = 346.8 MB，连续存储无 chunk）：latitude/longitude/elevation/timezone/country/state/county/gid_full
- **⚠ 覆盖陷阱**: v3.2.2 名为 "CONUS" 实为 **GOES-East+West 全视域网格**——lat 14.5~49.4（含墨西哥南部）、lon -160.4~-60.6（夏威夷~波多黎各），像素 0 位于夏威夷西南海域 (22.1N, -160.4W, tz=-10)。**不能假设像素序从美国本土开始**，任何区域提取必须先过 meta 空间过滤
- 像素按 `gid_full` 升序排列（首像素 gid=75456，非 0）

### 2. 访问路径决策

| 路径 | 结论 |
|------|------|
| developer.nrel.gov API / HSDS | **当前网络 DNS 不通**，不可用 |
| h5coro (S3Driver) | 需 AWS 凭证，匿名场景不可用 |
| **h5coro (HTTPDriver)** | **可用**，读纯数值数据集（/ghi 等）最快 |
| h5py + fsspec(http) | 可读 compound meta，但 h5py 大块请求跨境超时 |
| **meta 走 HTTP Range 流式下载** | **最优**：拿磁盘偏移后 requests 拉字节段，numpy 本地解析 |

### 3. h5coro 读取要点（/ghi 部分读取）

```python
from h5coro import h5coro
from h5coro.webdriver import HTTPDriver

h5o = h5coro.H5Coro(URL, HTTPDriver,
                    credentials=None,        # 必须 None: 传 "" 会加空 Bearer 头 → S3 400
                    cacheLineSize=131072,    # 默认 4MB 跨境读超时, 降到 128KB
                    verbose=False, errorChecking=False)

arr = h5o.readDatasets(
    [{"dataset": "/ghi", "hyperslice": [[row0, row1], [pix0, pix1]]}])["/ghi"]
# 注意: 不支持 h5o['/ghi'] 下标; hyperslice 为 [[start,end), [start,end)]
```

- h5coro **不支持 compound（meta）与属性**（units/scale_factor 等均返回 None），量纲/定位需间接验证

### 4. meta 流式下载与 ERCOT 像素定位（核心步骤）

```python
# 1) h5py 轻量打开只取结构信息 (fsspec 1MB 块, 大块会 aiohttp 超时)
f = fsspec.open(URL, "rb", block_size=1024*1024,
                client_kwargs={"timeout": aiohttp.ClientTimeout(total=120)}).open()
with h5py.File(f, "r") as h5:
    meta = h5["meta"]
    off = meta.id.get_offset()          # 2636192 (连续存储, chunks=None 时有效)
    n = meta.shape[0]

# 2) requests Range 流式拉取整个 meta 字节段 (346.8 MB)
headers = {"Range": f"bytes={off}-{off + n*122 - 1}"}
# ... iter_content(1MB) 落盘, 断点重试

# 3) numpy 本地解析 + ERCOT 空间过滤
META_DTYPE = np.dtype([("latitude","<f4"),("longitude","<f4"),("elevation","<i2"),
                       ("timezone","<f4"),("country","S36"),("state","S30"),
                       ("county","S38"),("gid_full","<i4")])
meta = np.fromfile(raw_path, dtype=META_DTYPE, count=n)
m = (meta["latitude"]>=25.8)&(meta["latitude"]<=36.5)& \
    (meta["longitude"]>=-106.7)&(meta["longitude"]<=-93.4)
idx = np.where(m)[0]    # ERCOT 像素在 /ghi 列轴上的索引
```

**实测结果（2026-09-27）**：
- 全域 meta 缓存 `nsrdb_v322_meta_raw.bin`（346.8 MB）+ 压缩 npz（7.7 MB）
- **ERCOT 像素 330,096 个**（其中德州 163,017 个，其余在俄克拉荷马/新墨西哥/路易斯安那/墨西哥湾水域）
- 索引范围 847,823 ~ 1,813,895；索引 npz 含 lat/lon/elevation/tz/gid_full

### 5. 端到端验证（时间-空间-量纲自洽）

对奥斯汀附近像素（idx 1530437，30.38N -97.89W，tz=-6）读全年两天的 288 步 GHI：

| 日期 | 峰值 | 峰值时刻 (UTC) | 当地时 (tz=-6) | 判定 |
|------|------|---------------|---------------|------|
| 1月1日 | 410 W/m² | 19:40 | 13:40 LST | 冬季晴空量级合理 |
| 7月1日 | **995 W/m²** | 18:15 | **12:15 LST** | 夏季正午，天文自洽 |

日循环峰值落在当地正午 ±1.5 h、峰值量级符合晴空模型，确认 uint16 值即 W/m²（scale_factor=1）且 time_index 为 UTC。反例验证：像素 0（夏威夷 tz=-10）1月峰值 655 W/m² @ 00:05 UTC = 14:05 HST，同样自洽。

### 8. 注意事项

- **量纲陷阱**：`/ghi` 属性（scale_factor/units）h5coro 读不出，首次使用须按第 5 节方法做日循环验证（某属性缺失 ≠ scale≠1）
- **时间轴**：time_index 是 UTC 变长字符串，转 LST 需逐像素用 meta.timezone；hyperslice 行号 = (day_of_year-1)×288 + slot
- **数据延迟**：2022 年文件为最终版；最近年份是 TMY/初步版（属性 `data_source`），工程精度用途优先选已定版年份
- 跨境网络读 1.8 TB 文件务必小缓存行/小块：h5coro 128 KB、fsspec 1 MB；两类驱动 4 MB 默认值均超时
- ERCOT 33 万像素 × 全年 105120 步（uint16）≈ 69 GB/年——按需取子时段/子区域，勿全量拉
