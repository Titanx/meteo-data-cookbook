## 背景

ASTER GDEM v3（Advanced Spaceborne Thermal Emission and Reflection Radiometer Global Digital Elevation Model）是 NASA 与日本 METI 合作生产的全球数字高程模型，基于 Terra 卫星 ASTER 传感器观测生成，空间分辨率 30 m。配套的 ASTWBD（ASTER Water Body Dataset）提供同分辨率的水体分类数据。2026-09-07 实测验证 ERCOT 区域 154 个 tile 全部下载成功，共 8.48 GB。

## 内容

### 数据集参数

| 参数 | ASTGTM.003 (GDEM) | ASTWBD.001 (WBD) |
|------|-------------------|-------------------|
| 全称 | ASTER Global DEM v3 | ASTER Water Body Dataset |
| 分辨率 | 30 m (0.000278°) | 30 m (0.000278°) |
| 投影 | EPSG:4326 (WGS84) | EPSG:4326 |
| tile 尺寸 | 3601 × 3601 像素 | 3601 × 3601 像素 |
| 分块 | 1° × 1° | 1° × 1° |
| 数据类型 | int16 (米) | int16 (dem) / uint8 (att) |
| DOI | 10.5067/ASTER/ASTGTM.003 | 10.5067/ASTER/ASTWBD.001 |
| 数据源 | NASA LP DAAC | NASA LP DAAC |

### 文件结构

**GDEM 每个 tile 包含 2 个文件**：
```
ASTGTMV003_N{lat}W{lon}_dem.tif  # 高程数据 (int16, 单位: 米)
ASTGTMV003_N{lat}W{lon}_num.tif  # 观测次数/QA (int16)
```

**WBD 每个 tile 包含 2 个文件**：
```
ASTWBDV001_N{lat}W{lon}_dem.tif  # 水体高程 (int16, 陆地=-9999 nodata)
ASTWBDV001_N{lat}W{lon}_att.tif  # 水体属性 (uint8)
```

**水体属性分类值**：

| 值 | 类型 | 说明 |
|----|------|------|
| 0 | 陆地 | 非水体 |
| 1 | 海洋 | 开阔海域 |
| 2 | 湖泊 | 内陆湖泊 |
| 3 | 河流 | 内陆河流 |

### 下载流程

```python
import earthaccess

# 凭证存储在 ~/_netrc (Windows) 或 ~/.netrc (Linux)
earthaccess.login(strategy="netrc")

# 搜索 GDEM tiles (ERCOT 区域)
results = earthaccess.search_data(
    short_name="ASTGTM",
    doi="10.5067/ASTER/ASTGTM.003",
    bounding_box=(-107.0, 25.0, -93.0, 34.0),  # ERCOT
    count=-1,  # 全部
)

# 下载
for granule in results:
    earthaccess.download(granule, local_path="./data/aster/gdem/")
```

### 数据读取

```python
import rasterio
import numpy as np

# 读取高程
with rasterio.open("ASTGTMV003_N32W097_dem.tif") as src:
    dem = src.read(1)
    print(f"高程: {dem.min()}m ~ {dem.max()}m")
    print(f"分辨率: {src.res[0]*111000:.0f}m")

# 读取水体属性
with rasterio.open("ASTWBDV001_N32W097_att.tif") as src:
    att = src.read(1)
    # 统计水体类型
    unique, counts = np.unique(att, return_counts=True)
    # 0=陆地, 1=海洋, 2=湖泊, 3=河流
```

### 适用场景

- ERCOT 区域地形对风电/光伏资源评估的影响分析
- 地形高程与闪电分布关系研究
- 水体分布与雷暴事件空间关联分析
- 地形坡度对雷达数据质量影响评估
- ERCOT 资源节点附近地形特征

### 不适用场景

- 实时高程数据需求（ASTER GDEM 为静态产品）
- 全球高精度 DSM（GDEM 为 DEM，不含建筑物/植被高度）
- 极地高纬度区域（数据覆盖到 83°N/S）
