## 背景

NEXRAD（Next Generation Weather Radar）是美国 NOAA 运营的 WSR-88D 多普勒天气雷达网络，全美约 160 个站点。本文档针对 **ERCOT 覆盖区域（德州及周边）** 的雷达数据获取。

NOAA 官方 NEXRAD Level 2 数据桶（`noaa-nexrad-level2`）匿名访问已关闭（2026 年实测 Access Denied），但 **Unidata 社区维护的实时分块桶（`unidata-nexrad-level2-chunks`）提供匿名可访问的实时流数据**。

### Python 下载示例

```python
import s3fs
import numpy as np

# 创建匿名 S3 文件系统
fs = s3fs.S3FileSystem(anon=True, client_kwargs={"region_name": "us-east-1"})
BUCKET = "unidata-nexrad-level2-chunks"

def get_latest_volume(sid):
    """获取雷达站最新体扫的所有分块"""
    path = f"{BUCKET}/{sid}"
    if not fs.exists(path):
        return None, []
    
    # 获取最新体扫
    volumes = sorted(fs.ls(path), reverse=True)
    if not volumes:
        return None, []
    
    latest = volumes[0]
    vol_name = latest.split("/")[-1]
    chunks = sorted(fs.ls(latest))
    return vol_name, chunks

def download_chunks(sid, output_dir="."):
    """下载雷达站最新体扫的所有分块"""
    import os
    vol_name, chunks = get_latest_volume(sid)
    if not chunks:
        print(f"  {sid}: 无数据")
        return
    
    os.makedirs(f"{output_dir}/{sid}_{vol_name}", exist_ok=True)
    for c in chunks:
        data = fs.read_bytes(c)
        cname = c.split("/")[-1]
        out_path = f"{output_dir}/{sid}_{vol_name}/{cname}"
        with open(out_path, "wb") as f:
            f.write(data)
    
    total_mb = sum(len(fs.read_bytes(c)) for c in chunks[:5]) / (1024*1024)
    print(f"  {sid}: {len(chunks)} 分块, ~{total_mb:.1f} MB, 保存至 {output_dir}/{sid}_{vol_name}/")

# 示例：下载 KFWS（达拉斯）最新体扫
download_chunks("KFWS", "./nexrad_chunks")
```

### 分块二进制格式说明

每个体扫由多个分块（chunk）组成，命名规则：

```
{SID}_{Volume}_{ChunkID}
```

其中：
- `SID`：雷达站 4 字母代码
- `Volume`：体扫序号（小整数，如 999, 928）
- `ChunkID`：分块标识，常见：
  - `_S`：头部（metadata）
  - `_D{NN}`：数据分块（D00-D99）
  - `_I{NN}`：索引分块

分块数量因体扫模式而异：
- 体扫模式 212（VCP 212）：约 55 个分块
- 体扫模式 215（VCP 215）：约 70-76 个分块
- 数据量：2-14 MB/体扫

### 与其他数据源对比

| 维度 | unidata chunks | RainViewer | GCP NEXRAD L2 |
|------|---------------|------------|---------------|
| 匿名访问 | ✅ 是 | ✅ 是 | ✅ 是（HTTP目录） |
| 实时性 | 秒级 | 5分钟 | 非实时 |
| 数据格式 | 原始二进制分块 | PNG 瓦片 | 原始 NEXRAD 文件 |
| 历史数据 | ❌ 仅最近~10体扫 | 2小时 | 完整归档 |
| 解析难度 | 高（需专有解码） | 低（标准图片） | 中（标准 NEXRAD） |
| 访问方式 | s3fs 匿名 | HTTP GET | gsutil / SDK |

### 数据解析限制

unidata chunks 使用自定义分块格式，**不是标准 NEXRAD 文件格式**。解析需要：
- 使用 wradlib 或 pyart 获取分块流（需检查是否支持此格式）
- 或手动解析二进制分块（需要 NEXRAD 协议文档）
- 替代方案：通过 RainViewer 获取可视化瓦片，通过 GCP 获取标准 NEXRAD 文件

## 适用场景

- ERCOT 区域实时雷暴监测
- 德州强对流天气追踪
- 风电/光伏区域雷达覆盖评估
- 雷达数据与电力市场联动分析

## 不适用场景

- 历史雷达数据归档（应使用 GCP 或 NCEI 归档）
- 需要标准 NEXRAD 格式文件（应使用 GCP）
- 仅需可视化（RainViewer 更简单）

## 已知限制

1. **数据保留短暂**：仅保留最近约 10 个体扫，需实时轮询获取
2. **非标准格式**：分块二进制格式，常规雷达库（pyart/wradlib）可能不直接支持
3. **无 L3 产品**：分块流仅含 Level 2 基数据，无反射率/速度产品
4. **体扫号抽象**：体扫编号为小整数（999/928 等），非时间戳，无法计算精确延迟
