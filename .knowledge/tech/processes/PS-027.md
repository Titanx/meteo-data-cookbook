# [PS-027] 季节预报 → 光伏缺口风险概率化（Open-Meteo Seasonal，未来45天，50成员）

> 最后更新: 2026-09-28
> 功能: 接 PS-025/026 的缺口×价格链路，把「缺口风险」从 **past/事后** 口径推进到 **未来 45 天概率化**。用 EC46/SEAS5 的 50 成员逐日短波集合，给 ERCOT 141 座光伏电站 fleet 的「缺日」概率、连阴 streak 概率、"危险云系(缺∧热)" 概率做出客观天气先验
> 结论一句话: 用**气候相对阈值**（历史 τ 分布）校正季节集合的过度平滑后，未来 45 天(2026-09-28~11-11)整体为**正常偏低的光照风险**——轻缺日均概率 ~7%、重缺 ~2%、无成员出现 ≥5 天连阴；且处暖季末/凉季初，**"缺日∧高温"危险云系结构上缺席**(峰值P ~2%) → 该窗口电价冲击主轴从"云×热"退化为"单纯云缺"

## 1. 背景

PS-023/024 已证缺口弹性对口径不敏感(+5.05~+6.15 %/GW)，PS-025/026 证持续时间(小时内+跨日)不放大、危险组合聚焦"特定极端小时"。遗留任务：把极端场景**概率化**——用 PS-017 已验证的季节预报辐照，给未来 45 天"哪些天可能有缺口/连阴"一个先验概率分布，供业务读风险排序。

## 2. 方法与链路

- 数据: `data/openmeteo_seasonal/*_seasonal_45d.json`（6 站 × 45 天 × **50 成员**逐日 shortwave_radiation_sum MJ/m²、temperature_2m_max）
- **① 晴空基准**: `pvlib.clearsky.haurwitz` 逐站逐日 GHI 总量(MJ/m²) → 与 seasonal 短波同量纲，相除得日传输率 `τ = forecast_sw / clear_sw ∈ [0,1]`（纯云量指数，自动消季节周期）
- **② fleet 聚合**: 141 座电站(30.9GW)按最近站点归属(容量加权)，得 fleet 逐日传输率 `fleet_tau`；权重 West 29%/South 21%/Houston_solar 19%/Dallas 17%/Houston 12%/North 2%
- **③ 缺口映射**: `sf_en[d,m] = fleet_clear_energy[doy] × (1 − fleet_tau)`，`fleet_clear_energy` 取自 141 站晴空小时序列的逐 doy 气候(李/秋 184~251 GWh)。⚠**日能源口径=缺口下界**，日内云相位不分辨
- **④ 气候校准(核心)**: 季节聚合逐日短波重度平滑 ⇒ 集合发散远小于真实日际变化(τ 中位 0.68~0.76、成员几乎不<0.5)。**不用绝对 τ 阈值**，改用**历史 τ 分布**(2025-26 物理缺口, 602 天)的 Q25=0.52/Q10=0.38 作"轻缺/重缺日"相对阈值，把预报 τ 映射成"比气候最差成"的尾部概率
- **⑤ 风险事件**: 轻缺日=τ≤Q25、重缺日=τ≤Q10、热日=fleet max 温≥32°C、危险=轻缺∧热、连阴=成员序列(相干)的 max run
- 输出: `seasonal_shortfall_risk.csv`(逐日) / `_weekly.csv` / `seasonal_streak_risk.csv`

## 3. 结果（2026-09-28 初始预报）

### 3.1 未来45天风险读数

| 指标 | 数值 |
|---|---|
| 轻缺日均概率 (τ≤Q25) | **~7%** (重缺 ~2%) |
| τ 中位 vs 历史中位 | 0.68~0.76 vs 0.70 → 接近常年阳光 |
| 连阴最长 (50成员) | max 5 天，**P(≥5天)=4%，P(≥7天)=0** |
| 危险云系(缺∧热)峰值 | **2%** (10-01)，此后 0 |
| 逐日 P90 缺口 | 常态 ~80-100 GWh，阴天尖峰 ~140-160 GWh |
| 逐周信号 | W1(10/01-03)见短暂阴窗 P轻缺↑0.14-0.22；W5-W6(10底-11初)小幅抬升 0.10-0.12 |

### 3.2 关键结构发现
- **危险云系(缺∧热)在本窗口缺席**：暖季末凉季初，高温日(≥32°C)迅速归零(10/03 起 P_热日=0) ⇒ "云×热"这一 PS-024/026 认定的高风险组合**季节性地退场**，剩余的是"单纯云缺"(缺而不热)，价格冲击温和。
- **相对气候校准改变读数**：绝对 τ<0.5 阈值下集合几乎无"缺日"(P≈0.06、无连阴)，是过度平滑的伪结论；换成历史 Q25/Q10 相对阈值后恢复到可读概率(~7%/~2%)且与历史晴雨频率量级相符。

## 4. 方法与局限（诚实声明）

1. **未校准概率**: 无多年季节回算(需 WMO S2S/ECMWF 认证, PS-020) ⇒ 概率是**原始集合频率**，非校准后概率；只适合读**风险相对排序**，不宜当精确百分率
2. **欠发散残留**: 即使相对校准，季节集合日际方差仍偏小 ⇒ 轻缺日概率仍是**真实值下界**(低估方向)
3. **单点→fleet 摊平**: 6 站预报覆盖少、电站按最近站归属 ⇒ 局地云系被摊平，或缺日概率轻度低估
4. **日能源口径**: 无法分辨日内云相位，逐小时尖峰缺口(PS-022 关键)不在本口径；本输出回答"多阴/连阴"而非"单小时尖峰"
5. **温度-负荷**: 危险云系用绝对 32°C 热日、未耦合实时负荷预测；本窗口无热日，结论对该选择稳健
