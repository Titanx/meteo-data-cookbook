## 背景

LMI（Lightning Mapping Imager）是中国风云四号系列静止轨道气象卫星搭载的**闪电成像仪**，是 GOES GLM 的中国对应载荷。LMI 通过 777.4 nm 近红外通道光学探测，以 2 ms 帧率凝视中国及周边区域，提供连续闪电观测。FY-4A（104.7°E）于 2017 年发射，FY-4B（133°E）于 2021 年发射，FY-4C（105°E）于 2025 年发射。

## 内容

### 仪器参数

| 参数 | FY-4A LMI | FY-4B LMI | FY-4C LMI |
|------|-----------|-----------|-----------|
| 定位 | 104.7°E | 133°E | 105°E |
| 发射时间 | 2017-09-25 | 2021-06-03 | 2025-06-30 |
| 探测原理 | 光学成像 777.4 nm | 同左 | 同左 |
| 空间分辨率 | **7.8 km** 星下点 | 7.8 km | 7.8 km |
| CCD 面阵 | 400 × 600 单元 | 同左 | 同左 |
| 帧率 | 2 ms（500帧/秒） | 同左 | 同左 |
| 探测效率 | 白天>70%，夜晚>90% | 同左 | 同左 |
| 虚警率 | <10% | <10% | <10% |
| 数据类型 | 总闪电（IC+CG 不区分） | 同左 | 同左 |
| 观测模式 | 3-9月北半球 / 9-3月南半球 | 连续观测 | 连续观测 |

### 数据产品

| 产品 | 说明 | 时间分辨率 | 空间分辨率 | 格式 |
|------|------|-----------|-----------|------|
| **LMIE** | Event 产品（单像素事件） | 1 分钟 | 7.8 km | NetCDF |
| **LMIG** | Group 产品（相邻事件聚类） | 1 分钟 | 7.8 km | NetCDF |
| **LMIF** | Flash 产品（完整闪电） | 1 分钟 | 7.8 km | NetCDF |

**三级结构**（与 GLM 相同）：Event（单像素光信号）→ Group（16.5 km 内相邻 Event）→ Flash（完整闪电闪击）

### LMIE 科学变量

| 变量 | 说明 | 类型 | 单位 |
|------|------|------|------|
| LON | 事件经度 | Float | degree |
| LAT | 事件纬度 | Float | degree |
| ETT | 事件 TAI 时间 | Float | ms（从 2000-01-01 TAI 起算） |
| EOT | 事件观测时间 | Float | ms |
| ER | 事件辐射强度 | Float | μJ/m²/ster |
| EFP | 事件足迹 | Float | km |
| EA | 事件地址 | Float | 无 |
| EGA | 事件所属 Group 地址 | Float | 无 |
| EXP | 事件 X 像素 | Float | 0-400 |
| EYP | 事件 Y 像素 | Float | 0-600 |
| DQF | 数据质量标记 | Byte | 0=good, 1=conditional, 2=out_of_range, 3=no_value |

### 数据源

| 数据源 | 认证 | 延迟 | 时间范围 | 说明 |
|--------|------|------|----------|------|

### 数据获取

#### 方案一：NSMC 官方门户（实时数据）

1. 注册账号：https://satellite.nsmc.org.cn/DataPortal/cn/home/index.html
2. 选择：卫星=FY-4A → 仪器=LMI → 设置时间范围 → 检索
3. 勾选文件 → 下载

#### 方案二：中科院订正数据集（2019-2023，公开）

- DOI: [10.11888/Atmos.tpdc.303312](https://doi.org/10.11888/Atmos.tpdc.303312)
- 来源：国家青藏高原科学数据中心
- 格式：CSV + NetCDF，每日文件
- 覆盖：2019-2023 年每年 3-9 月，北半球观测区域
- 包含：订正后的闪电事件时间、经纬度、辐射强度、云顶高度
- 引用：Zhang et al. (2026), ESSD, https://doi.org/10.5194/essd-18-5773-2026

### 数据解析

import xarray as xr

# 读取 LMIE 文件
ds = xr.open_dataset('FY4A-_LMI---_N_REGX_1047E_L2-_LMIE_SING_NUL_20200701000000_20200701000449_7800M_N02V1.NC')
lon = ds['LON'].values

radiance = ds['ER'].values
