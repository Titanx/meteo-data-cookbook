# [PS-030] 西班牙光伏最小链路（免注册数据源复刻 pvlib 出力建模）

> 最后更新: 2026-09-28
> 功能: 承接 PS-029 的"零门槛路径"，用**全部免注册**的数据源（GEM + NASA POWER + Energy-Charts/OMIE）把 ERCOT 的 NSRDB+pvlib 出力建模（PS-021）复刻到西班牙，并与实际发电对照验证
> 结论一句话: 链路**可建成且验证通过**——逐小时相关 **r=0.9845**、标定后年能量比 **0.979**（潜力 39.6 vs 实际 40.4 TWh）；但**ERCOT 的标定参数不可移植**：沿用 ERCOT 的 ILR=1.30 高估 **50%**，西班牙需降到 **ILR≈0.85**；电价方向"光伏出力↑→电价↓"（−2.52 %/GW）与 ERCOT（−4.9）**同号**

## 1. 背景

PS-029 判定西班牙是 ERCOT 风光缺口链路的理想外部参照市场，并明确"零门槛路径 = OMIE(价) + PVGIS(辐照) + GEM(清单)"。本流程把该路径落地，并解决三个工程问题：辐照分量来源、实际发电来源、跨市场参数标定。

## 2. 数据源（全部免注册，均实测通过）

| 环节 | 数据源 | 说明 | 本轮 |
|---|---|---|---|
| 电站清单 | GEM 全球光伏追踪 `gem_solar_2026-08.csv` | 西班牙 operating & start-year≤2023 | 2,080 座 / 27.66 GW → 0.5° 网格聚合 **120 采样点（96.3% 容量）** |
| 辐照+气温 | **NASA POWER** hourly point (MERRA-2) | `ALLSKY_SFC_SW_DWN/DNI/DIFF` + `T2M`，逐小时，2001–，无 token | 120 点 × 8,760 h |
| 辐照交叉校验 | PVGIS-SARAH3 (EUMETSAT) | 逐小时面内辐照 `G(i)`，欧洲，2005–2023 | 前 12 大站点 |
| 实际发电/负荷 | **Energy-Charts** (Fraunhofer ISE) | 15 min，`country=es`，含 Solar / Wind onshore / Load | 35,040 点（Solar 峰值 17,668 MW） |
| 日前电价 | Energy-Charts `price?bzn=ES`（OMIE 口径） | 逐小时 €/MWh | 8,760 点，均价 **87.10 €/MWh** |

**关键工程经验**：Open-Meteo 存档 API 在批量取数（212 点、每批 20 点）时触发 `Minutely/Hourly API request limit exceeded` 被**硬阻断**（限流按"点×次"计），不适合本场景；**NASA POWER 无条件放行且提供完整 GHI/DNI/DHI 分量**，是免注册方案里唯一能支撑单轴跟踪建模的选择。PVGIS 虽质量更高但只给面内辐照、无分量。

## 3. 链路（与 PS-021 完全同法）

`NASA POWER GHI/DNI/DHI/T2m` → pvlib `solarposition` → `tracking.singleaxis`（±60°、backtracking、gcr 0.35）→ `irradiance.get_total_irradiance` (POA)
→ 电池温度 `Tcell = Tamb + POA/800×25` → PVWatts DC `pdc0·POA/1000·(1+γ(Tcell−25))·0.86`（γ=−0.0037）→ AC `min(pdc×0.96, 装机)` → 120 点求和 → fleet 潜力 MW。
晴空反事实另算一遍（`clearsky.simplified_solis`, aod700=0.1, pw=1.5）。

## 4. 验证结果（2023）

| 指标 | 值 |
|---|---|
| 逐小时相关（潜力×实际） | **r = 0.9845**（lag 0；lag±1 降至 0.904/0.951 ⇒ 时点对齐正确） |
| 年能量比（标定后） | **0.979**（潜力 39.6 vs 实际 40.4 TWh） |
| 容量因子 | 潜力 0.170 vs 实际 0.173 |
| 月比值区间 | **0.878 – 1.197**（夏秋偏低、深冬偏高 → NASA POWER 冬季辐照略高估） |
| 晴空/实际 能量比 | 1.201 |

## 5. 核心发现：标定参数不可跨市场移植

ILR 扫描（年潜力/实际）：

| ILR | 0.80 | 0.85 | 0.90 | 1.00 | 1.10 | 1.20 | **1.30 (ERCOT标定)** |
|---|---|---|---|---|---|---|---|
| 比值 | 0.92 | **0.979** | 1.036 | 1.151 | 1.266 | 1.381 | **1.496** |

⇒ 直接沿用 ERCOT 的 ILR=1.30 会**高估 50%**；标到实际需 **ILR≈0.85**。原因：
(a) 西班牙光伏以固定倾角为主、跟踪器比例低于 ERCOT ⇒ 单位容量 POA 增益更小；
(b) 直流/交流比普遍低于 ERCOT 的 1.25~1.35；
(c) GEM 清单口径 vs TSO 可见发电口径差（分布式自消费未计入实际）。
**与 PS-029 的"结构性差异"判断一致：跨市场复刻必须重新标定容量/ILR 类参数。**

## 6. 电价弹性（白天，ln(price) ~ X + 风电 + 负荷 + 小时/月 FE）

| 解释变量 | 弹性 %/GW | SE |
|---|---|---|
| 实际光伏水平 | **−2.521** | 0.515 |
| 晴空缺口（云） | −0.696 | 0.637 |
| 天气缺口（潜力−实际） | −53.697 | 1.806 |

- ① **实际光伏水平 −2.52 %/GW 与 ERCOT（−4.9）同号** ⇒ "光伏出力↑→电价↓"的方向规律跨市场成立。
- ② 晴空缺口 −0.70 不显著，与 ERCOT 的 +5 %/GW 相反。
- ③ 天气缺口系数 −53.7 是**共线性伪象**：缺口 = 潜力 − 实际，与实际近乎共线 ⇒ 两者系数不可分开识别（与 PS-028 机制检验 E 同一问题），**不应解读为因果弹性**。
- ⚠ 2023 年西班牙**尚无负电价**（当年 0 小时；首次负价在 2024-04-01），且受"伊比利亚例外"天然气限价机制影响 ⇒ 本表只宜作**方向性参考**。

## 7. 局限

1. NASA POWER 是 MERRA-2 再分析（非卫星），冬季辐照略高估（月比值最高 1.20）
2. GEM 清单为 2026-08 快照按 `start-year` 回推，与 2023 真实在建/投产清单存在偏差
3. 实际发电取 ENTSO-E / Energy-Charts 口径，与 REE 官网口径可能略有差异
4. 2023 年无负电价且市场机制特殊，"缺口→电价"弹性不具代表性
5. 未做节点级或 15 分钟级对齐；未与 ESIOS 实时出力交叉校验（需 token）
