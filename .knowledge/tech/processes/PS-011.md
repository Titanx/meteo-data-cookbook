## 背景

GLM（Geostationary Lightning Mapper）是搭载在 GOES-16/18/19 上的**首个业务化地球静止轨道闪电测绘仪**，通过 777.4 nm 近红外波段光学探测，以 2 ms 帧率连续凝视西半球，提供云内闪、云地闪和云间闪的**总闪电**数据。2026-09-07 实测验证 GOES-18 当前数据可正常下载，匿名访问无需认证。

## 内容

### 仪器参数

| 参数 | 值 |
|------|-----|
| 传感器 | 凝视型 CCD 1372 × 1300 像素 |
| 波段 | 777.4 nm（氧气三重态吸收线） |
| 帧率 | 2 ms |
| 空间分辨率 | 8 km（星下点）~ 14 km（边缘） |
| 纬度覆盖 | ±54° |
| 探测效率 | 70-90%（昼夜），误报率 <5% |
| 数据延迟 | <20 秒（产品），<1 分钟（显示） |
| 数据类型 | 总闪电（IC+CG，无法区分类型） |

### 卫星平台

| 卫星 | 定位 | 状态 | 覆盖 | 推荐 |
|------|------|------|------|------|
| GOES-16 | 75°W（GOES-East） | 已退役归档 | 美洲 | 历史数据 |
| GOES-18 | 137°W（GOES-West） | **运行中** | 太平洋+美洲西部 | **德州实时数据** |
| GOES-19 | 75.2°W（GOES-East） | 运行中 | 美洲 | 数据较新 |

### 数据产品等级

| 级别 | 产品名 | 说明 | 格式 |
|------|--------|------|------|
| L1b | Events | 原始像素级探测（2 ms） | netCDF-4 |
| **L2** | **GLM-L2-LCFA** | **Events → Groups → Flashes** | **netCDF-4** |
| L3 | glmgoesL3 | 格点化 0.05° 网格 | netCDF-4 |

**L2 三级结构**：Event（单个像素光信号）→ Group（相邻 Event 聚合）→ Flash（完整闪电闪击）

### 数据源

| 数据源 | 认证 | 延迟 | 时间范围 | 说明 |
|--------|------|------|----------|------|
| **AWS S3** | ❌ 匿名 | 实时 | 各卫星运行期间 | **推荐，免认证** |
| Google Cloud | ❌ 匿名 | 实时 | 同 S3 | 备选 |
| GHRC DAAC (L3) | ✅ Earthdata | 归档 | 2023-04-14 至今 | 格点数据，需 earthaccess |

### 下载流程（S3 匿名推荐）

#### 路径结构

```
s3://noaa-goes{16/18/19}/GLM-L2-LCFA/{year}/{3位年积日}/{2位小时}/
```

示例：`s3://noaa-goes18/GLM-L2-LCFA/2026/250/00/`

#### 文件命名

```
OR_GLM-L2-LCFA_G18_s20262500000000_e20262500000200_c20262500000219.nc
  ↑ 产品前缀  ↑卫星  ↑start_time  ↑end_time  ↑creation_time
```

每个文件 = 20 秒数据，约 0.25-0.35 MB。

#### 脚本用法

```bash
# 下载 1 小时数据
python scripts/data_download/download_glm_l2.py -s 18 -b "2026-09-07 00:00" -e "2026-09-07 01:00"

# 下载指定卫星和更长时间段
python scripts/data_download/download_glm_l2.py -s 19 -b "2026-09-06 12:00" -e "2026-09-07 12:00"
```

#### Python 代码

```python
import boto3
from botocore import UNSIGNED, Config

s3 = boto3.client('s3', config=Config(signature_version=UNSIGNED))

# 列出文件
resp = s3.list_objects_v2(Bucket='noaa-goes18', 
                           Prefix='GLM-L2-LCFA/2026/250/00/')
for obj in resp['Contents']:
    print(obj['Key'])

# 下载
s3.download_file('noaa-goes18', key, 'local.nc')
```

### 数据解析

```python
import h5py
import numpy as np
from datetime import datetime, timedelta

GLM_EPOCH = datetime(2000, 1, 1)

with h5py.File('OR_GLM-L2-LCFA_G18...nc', 'r') as f:
    # 闪击位置
    lat = f['flash_lat'][:]
    lon = f['flash_lon'][:]
    energy = f['flash_energy'][:] * 1e-6  # J → MJ
    area = f['flash_area'][:] * 1e-6      # m² → km²
    quality = f['flash_quality_flag'][:]
    
    # 时间
    t0 = GLM_EPOCH + timedelta(seconds=f['product_time'][()])
    time_offset = f['flash_time_offset_of_first_event'][:] * 1e-6  # µs → s
    flash_times = [t0 + timedelta(seconds=float(off)) for off in time_offset]
```

### 区域裁剪（ERCOT Texas）

德州位于 GOES-16 星下点附近，分辨率最优。GOES-18 也能覆盖德州。

GLM 数据读取后可直接按经纬度裁剪：
```python
bbox = (-106.5, 25.5, -93.0, 36.5)  # ERCOT Texas
mask = (lon >= -106.5) & (lon <= -93.0) & (lat >= 25.5) & (lat <= 36.5)
texas_flashes = flashes[mask]
```

### 数据说明

- **探测效率**：~70-90%，昼夜均可，无海陆偏差
- **无法区分 IC/CG**：GLM 探测总闪电，不区分云内闪和云地闪
- **质量标记**：0 = 良好，其他值表示不同程度的质量问题
- **能量单位**：原始存储为 J（int16），需缩放因子 1e-6 转换为 MJ
