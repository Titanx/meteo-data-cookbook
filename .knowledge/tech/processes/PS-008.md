### 使用方法

```bash
# 下载全部站点最近30天
python download_sounding_parallel.py --days 30

# 只下载 ERCOT 区域
python download_sounding_parallel.py --region texas --days 30

# 只下载东亚区域
python download_sounding_parallel.py --region asia --days 30

# 指定日期范围
python download_sounding_parallel.py --start 2026-07-13 --end 2026-08-11

# 测试模式 (1天1站)
python download_sounding_parallel.py --dry-run

# 强制重新下载
python download_sounding_parallel.py --force --days 3
```

## 数据特征

### 垂直分辨率差异

| 区域 | 典型行数/次 | 分辨率类型 | 说明 |
|------|------------|-----------|------|
| 美国站 | 4000-8000 | 高分辨率 | 1秒级，含大量中间层（约51倍于东亚） |
| 中国站 | 100-200 | 标准分辨率 | 仅规定层（等压面、特性层） |
| 日本站 | 30-70 | 稀疏 | 规定层，上层截断（~200hPa 起） |

### 热力指数

新 WSGI 格式中热力指数以 HTML 表格展示，需要从 HTML 去标签后的纯文本中正则提取。关键指数：

| 指数 | 全称 | 单位 | 可用性 |
|------|------|------|--------|
| CAPE | Convective Available Potential Energy | J/kg | 常缺失 |
| **DCAPE** | Downward CAPE | **J/kg** | **可靠提取** |
| CINS | Convective Inhibition | J/kg | 偶缺失 |
| SHOW | Showalter Index | °C | 可靠 |
| LIFT | Lifted Index | °C | 可靠 |
| TOTL | Total Totals Index | °C | 可靠 |
| BRCH | Bulk Richardson Number | — | 偶缺失 |

### 数据质量

- 零缺测（测试确认）
- 中国站数据延迟 <12 小时
- 美国站高分辨率数据包含完整中间层（已不是常规的"规定层"数据）

## 并行下载策略

```python
from concurrent.futures import ThreadPoolExecutor, as_completed

with ThreadPoolExecutor(max_workers=5) as executor:
    futures = {}
    for station, date, hour in tasks:
        future = executor.submit(download_one, station, date, hour)
        futures[future] = (station, date, hour)
    
    for future in as_completed(futures):
        # 立即处理已完成的结果
        status, sid, dt, rows, info = future.result()
        # 进度更新
```

### 性能对比

| 模式 | 耗时 | 加速比 |
|------|------|--------|
| 串行 | ~7 小时（估算） | 1x |
| 5线程并行 | ~36 分钟 | 11.7x |

## 已知限制

1. **72251 Dallas-FW 12Z 系统性无数据**：该站可能仅 00Z 进行探空
2. **CAPE 在新 WSGI 格式中缺失**：提取 DCAPE 作为替代
3. **中国站分辨率低**：需插值到标准层才能与美国站比较
4. **ConnectionResetError**：中国网络环境常见，max_retries=2 可解决
