## 背景

GPM IMERG（Integrated Multi-satellitE Retrievals for GPM）是 NASA 的全球卫星降水产品，融合多颗卫星微波/红外观测和地面雨量计校准，提供 1998 年至今的全球降水估计。2026-09-07 实测验证 **ERCOT 区域数据完全可下载**，30 分钟产品 7.8 MB/文件，日产品 31 MB/文件。

## 内容

### 数据源信息

| 产品 | 产品名 | 分辨率 | 延迟 | 文件大小(ERCOT区域) |
|------|--------|--------|------|-------------------|
| **30 分钟** | GPM_3IMERGHH | 0.1° × 0.1°, 30 分钟 | 4h(Early)~3.5月(Final) | **~7.8 MB** |
| **日产品** | GPM_3IMERGDF | 0.1° × 0.1°, 1 天 | 同上 | **~31 MB** |
| **月产品** | GPM_3IMERGM | 0.1° × 0.1°, 1 月 | 同上 | 待测 |

### 下载流程

```python
import os
import earthaccess
from datetime import datetime, timezone

# 方式一：环境变量配置（推荐，避免明文密码）
os.environ['EARTHDATA_USERNAME'] = 'your_username'
os.environ['EARTHDATA_PASSWORD'] = 'your_password'
auth = earthaccess.login(strategy='environment')

# 方式二：interactive 模式（首次运行）
# auth = earthaccess.login(strategy='interactive', persist=True)

# 搜索 30 分钟产品（ERCOT 区域）
results = earthaccess.search_data(
    short_name="GPM_3IMERGHH",
    bounding_box=(-106.5, 25.5, -93.0, 36.5),  # Texas 边界
    temporal=(datetime(2024, 7, 15, tzinfo=timezone.utc),
              datetime(2024, 7, 16, tzinfo=timezone.utc)),
    count=10,
)

# 下载
files = earthaccess.download(results[0], "./data/imerg/")
```

### 数据文件结构

**HDF5 文件结构**（30 分钟产品）：
```
Grid/
├── lat                    (1800,)         # 纬度
├── lon                    (3600,)         # 经度
├── time                   (1,)            # 时间
├── precipitation          (1, 3600, 1800) # 降水率 mm/hr
├── precipitationQualityIndex (1, 3600, 1800) # 质量指数
├── probabilityLiquidPrecipitation (1, 3600, 1800) # 液态降水概率
├── randomError            (1, 3600, 1800) # 随机误差
├── Intermediate/
│   ├── IRprecipitation    (1, 3600, 1800) # 红外降水估计
│   ├── MWprecipitation    (1, 3600, 1800) # 微波降水估计
│   ├── precipitationUncal (1, 3600, 1800) # 未校准降水
│   └── IRinfluence        (1, 3600, 1800) # 红外影响权重
└── ...
```

**注意**：全局网格 3600×1800 = 6,480,000 格点。读取全部数据约需 25 MB 内存（float32）。

### 读取降水数据

```python
import h5py
import numpy as np

with h5py.File("3B-HHR.MS.MRG.3IMERG.20240715-S000000-E002959.0000.V07B.HDF5", 'r') as f:
    lat = f['Grid/lat'][:]
    lon = f['Grid/lon'][:]
    precip = f['Grid/precipitation'][0]  # shape (3600, 1800)
    
    # ERCOT 区域裁剪
    lon_idx = np.where((lon >= -106.5) & (lon <= -93.0))[0]
    lat_idx = np.where((lat >= 25.5) & (lat <= 36.5))[0]
    precip_texas = precip[np.ix_(lon_idx, lat_idx)]
    
    print(f"ERCOT 区域降水: min={np.nanmin(precip_texas):.2f}, "
          f"max={np.nanmax(precip_texas):.2f}, "
          f"mean={np.nanmean(precip_texas):.2f} mm/hr")
```

### 数据量估算（ERCOT 区域）

| 产品 | 单文件 | 每日 | 每月 | 每年 |
|------|-------|------|------|------|
| 30 分钟 | ~7.8 MB | 48×7.8 = **374 MB** | ~11 GB | ~134 GB |
| 日产品 | ~31 MB | **31 MB** | ~930 MB | ~11 GB |

**建议**：对于历史分析，优先使用**日产品**（31 MB/天）而非 30 分钟产品（374 MB/天），除非需要研究降水日内变化。

### 子集化下载（节省带宽）

earthaccess 支持通过 `subset=True` 和 `bbox` 参数只下载目标区域，避免下载全球格点：

```python
results = earthaccess.search_data(
    short_name="GPM_3IMERGHH",
    bounding_box=(-106.5, 25.5, -93.0, 36.5),  # 自动裁剪

    count=100,

# 下载时自动子集化
files = earthaccess.download(results, "./data/imerg/", bbox=(-106.5, 25.5, -93.0, 36.5))
```

## 适用场景

- 长时间序列降水分析（1998 年至今）
- ERCOT 区域极端降水事件监测
- 德州降水气候态统计
- 与 HRRR 模式预报降水对比验证
- 卫星降水数据与地面雨量计融合分析

## 不适用场景

- 实时性要求 < 4 小时（Early Run 延迟约 4h，Final Run 延迟 3.5 月）
- 无需 Earthdata 注册的场景
- 高时空分辨率需求（HRRR 3km/1h 优于 IMERG 10km/30min）
- 临时单次查询（不配置 Earthdata 的情况下，RainViewer 更便捷）
