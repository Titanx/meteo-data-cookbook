# [GL-009] 气象数据 API 凭证安全管理实践

> **类型**: guideline
> **成熟度**: verified

> **最后引用**: 2026-09-07

## 背景

气象数据项目涉及多个需要认证的 API（NASA Earthdata、EIA、GridStatus.io、CMA NSMC），凭证管理不当会导致账号泄露和安全风险。2026-09-07 建立统一的凭证安全管理实践，确保所有 API key 和账号密码不入 git，且脚本可自动加载。

## 内容

### 凭证分类与管理方式

| 凭证类型 | 管理方式 | 文件位置 | 适用 API |
|----------|---------|----------|---------|
| Earthdata 账号 | netrc | `~/_netrc` (Win) / `~/.netrc` (Linux) | NASA Earthdata, GES DISC, GHRC |
| API Key (文本) | .env | 项目根目录 `.env` | EIA, GridStatus.io |
| CMA 账号 | config.ini | `~/.nmcdev/config.ini` | nmc-met-io (有限可用) |

### 方案一：netrc（Earthdata 认证）

**文件格式**（`C:\Users\44263\_netrc`）：
```
machine urs.earthdata.nasa.gov
  login your_username
  password your_password
```

**Python 使用**：
```python
import earthaccess
# 自动读取 netrc 文件，无需硬编码
earthaccess.login(strategy="netrc")
```

**要点**：
- Windows 文件名 `_netrc`（无点），Linux 为 `.netrc`
- 文件权限建议 600（仅用户可读）
- 支持 earthaccess、requests-negotiate-auth 等库自动读取

### 方案二：.env 文件（API Key 管理）

**文件格式**（`c:\work\meteo\.env`）：
```
EIA_API_KEY=your_eia_api_key
GRIDSTATUS_API_KEY=your_gridstatus_api_key
```

**Python 自动加载**：
```python
from pathlib import Path
import os

_env_path = Path(__file__).resolve().parents[2] / ".env"
if _env_path.exists():
    for line in _env_path.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if line and not line.startswith("#") and "=" in line:
            k, v = line.split("=", 1)
            os.environ.setdefault(k.strip(), v.strip())
```

**要点**：
- `.env` 文件放项目根目录
- 脚本自动加载，无需手动 `$env:VAR = "..."` 设置
- `os.environ.setdefault()` 不覆盖已有环境变量，支持命令行临时覆盖

### .gitignore 配置

```gitignore
# 凭证文件 (禁止入库)
.env
_netrc
.netrc
.nmcdev/
```

### 新脚本凭证使用规范

1. **Earthdata 认证**：`earthaccess.login(strategy="netrc")`，不使用 `earthaccess.login(strategy="interactive")`
2. **API Key**：通过 `.env` 自动加载，不使用 `os.environ["KEY"] = "value"`
3. **CMA 认证**：通过 `~/.nmcdev/config.ini`，不硬编码在脚本中
4. **命令行临时覆盖**：`$env:GRIDSTATUS_API_KEY = "temp_key"` 优先级高于 .env（因 `setdefault` 不覆盖）
5. **提交前检查**：确保 `git diff --cached` 中无 `password=`、`key=`、`login=` 等敏感字符串
