## 背景

气象雷达数据是强对流天气监测和预警的核心数据源。本文档综合评估了所有可**自动匿名获取**（无需注册、无需 API key、无需付费）的雷达数据源，重点覆盖 **ERCOT 区域（德州及周边）**。

|--------|--------|--------|---------|----------|---------|

### ❌ 不可匿名访问

| 数据源 | 原因 | 替代方案 |
|--------|------|---------|
| noaa-nexrad-level2 | Access Denied | unidata chunks / GCP |
| noaa-nexrad-level3 | 桶不存在 | GCP NEXRAD L3 |
| NCEI THREDDS | 404 URL 变更 | GCP 归档 |
| Azure Blob | 中国网络超时 | GCP 替代 |
| OpenWeatherMap | 401 需要 API key | RainViewer 替代 |
| CDS ERA5 | 需要注册 | 不适用 |

## 各数据源详情

### 1. unidata-nexrad-level2-chunks（推荐实时方案）

**简介**：Unidata 社区维护的 NEXRAD Level 2 实时分块流，203 个 NEXRAD 站点，AWS S3 匿名访问。

**访问方式**：
```python
import s3fs
fs = s3fs.S3FileSystem(anon=True, client_kwargs={"region_name": "us-east-1"})
# 列出所有站点
stations = fs.ls("unidata-nexrad-level2-chunks/")
# 获取 KFWS 最新体扫分块
chunks = sorted(fs.ls(f"unidata-nexrad-level2-chunks/KFWS/999"))
```

**ERCOT 覆盖**：18 站全部可达，每站 24-76 个分块，单个体扫 2-14 MB。

**限制**：仅保留最近~10 个体扫；非标准 NEXRAD 文件格式；体扫编号为小整数（非时间戳）。

### 2. RainViewer API（推荐可视化方案）

**简介**：全球 1200+ 雷达站拼图，免费无 key，提供 256/512 分辨率 PNG 瓦片。

**访问方式**：
```python
import requests
# 获取元数据
r = requests.get("https://api.rainviewer.com/public/weather-maps.json")
data = r.json()
latest_ts = data["radar"]["past"][-1]["time"]  # 或 int
# 获取瓦片
tile = requests.get(f"https://tilecache.rainviewer.com/v2/radar/{latest_ts}/256/8/8/8.png")
```

**ERCOT 覆盖**：德州区域 3x3 瓦片（z=8）全部可达，每块约 1.3 KB（256px）或 3.2 KB（512px）。

**参数**：
- 基础 URL: `https://tilecache.rainviewer.com/v2/radar/{timestamp}/{resolution}/{z}/{x}/{y}.png`
- 分辨率: `256` 或 `512`（像素）
- 缩放级别: z=8 适合德州区域
- 时间范围: 约 2 小时历史帧，无预报帧

**限制**：仅 PNG 瓦片，非原始反射率数据；低分辨率不适合精细分析。

### 3. GCP 公开数据集（推荐归档方案）

**简介**：Google Cloud Storage 上的 NOAA 公开数据集，含 NEXRAD L2/L3 和 GOES 数据。

**访问方式**：
```bash
# HTTP 目录浏览
# https://storage.googleapis.com/gcp-public-data-nexrad-l2/

# 使用 gsutil
gsutil ls gs://gcp-public-data-nexrad-l2/KFWS/
```

**可用桶**：
- `gcp-public-data-nexrad-l2` — NEXRAD Level 2 完整体扫
- `gcp-public-data-nexrad-l3` — NEXRAD Level 3 产品
- `gcp-public-data-goes-16` — GOES 卫星数据

**限制**：HTTP 直接访问仅能列出目录，无法下载具体文件；需 `gcloud`/`gsutil` SDK 下载。

### 4. NWS API（元数据方案）

**简介**：美国国家气象局官方 API，提供雷达站元数据、警报信息等。

**端点**：
```python
import requests
# 获取全部 208 个雷达站信息
stations = requests.get("https://api.weather.gov/radar/stations").json()
# 获取 KFWS 站详情
kfws = requests.get("https://api.weather.gov/radar/stations/KFWS").json()
# 获取德州警报
alerts = requests.get("https://api.weather.gov/alerts/active?area=TX").json()
```

**限制**：无实时雷达数据，仅元数据；`/latest` 端点返回 404（可能已废弃）。

### 5. NOMADS HRRR（模式预报方案）

**简介**：NOAA NOMADS 服务器提供 HRRR/RAP/GFS 等模式数据，含雷达等效反射率。

**端点**：
```python
# HRRR 产品目录
url = "https://nomads.ncep.noaa.gov/pub/data/nccf/com/hrrr/prod/"
```

**ERCOT 覆盖**：HRRR 3km 分辨率覆盖全美，含 `REFC`（复合反射率）和 `REFD`（最大反射率）等雷达等效产品。

**限制**：模式数据，不是真实雷达观测；代表性约 1 小时延迟。

### 6. IEM HTTP（辅助方案）

**简介**：Iowa Environmental Mesonet 提供 NEXRAD GIS 服务和元数据。

**端点**：
```python
# GIS 服务目录
requests.get("https://mesonet.agron.iastate.edu/data/gis/images/")
# 雷达站 JSON
requests.get("https://mesonet.agron.iastate.edu/json/radar.py?station=KFWS")
```

**限制**：实时 PNG 拼图返回 404；GIS WMS 服务不可达。

### 7. NASA Earthdata Search（卫星降水方案）

**简介**：GPM/IMERG 全球卫星降水数据的元数据搜索。

**端点**：
```python
# 搜索 IMERG 数据
requests.get("https://cmr.earthdata.nasa.gov/search/granules.json?short_name=GPM_3IMERGDL&page_size=1")
```

**限制**：仅元数据搜索，实际数据下载需要 NASA Earthdata 登录。

## 数据源选择决策树

```
需要雷达数据？
├─ 需要实时原始数据 → unidata chunks (s3fs 匿名)
├─ 需要实时可视化 → RainViewer API (HTTP GET)
├─ 需要历史归档 →
│   ├─ 标准 NEXRAD 格式 → GCP NEXRAD L2 (gsutil)
│   └─ 仅元数据/搜索 → NWS API / Earthdata
├─ 需要模式预报 → NOMADS HRRR (含 REFC/REFD)
└─ 需要卫星降水 → GPM/IMERG (需 Earthdata 登录)
```
